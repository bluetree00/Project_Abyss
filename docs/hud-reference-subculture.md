# 서브컬처 액션 게임 HUD — 공통 패턴 레퍼런스

> 목적: RelicFairy HUD 디자인의 **컨벤션 근거**. 여러 서브컬처(가챠/액션) 게임을 훑어 **공통점만** 추려, 각 요소를 어디에·어떻게 두는지의 표준을 정리한다.
> 조사 대상: **원신(Genshin)** · **명조(Wuthering Waves)** · 붕괴3rd · 퍼니싱 그레이레이븐(PGR) · 젠레스 존 제로(ZZZ) · 토워 오브 판타지(ToF) · 승리의 여신 니케.
> ⚠️ HUD 레이아웃 관찰 기반 요약(버전에 따라 세부 상이). 픽셀 스펙이 아니라 **배치·표현 컨벤션**.

---

## RelicFairy 요소 ↔ 서브컬처 대응
| RelicFairy | 대응 개념 | 조사 초점 |
|---|---|---|
| 장비(무기 2) | 무기/스탠스/캐릭터 스위치 | 장착·전환·활성 표시 |
| **고유 캐릭터 기술(Q=유물)** | 시그니처·궁극·해방 | 강조·게이지 표현 |
| **장비 스킬 2(E·R)** | 무기/스킬 슬롯 | 스킬 클러스터 |
| 서약 | 로그라이크 축복/각인 | 빌드 아이콘 리스트 |
| 버프 | 버프/디버프 | 아이콘+타이머+스택 |

## 1. 장비(무기) 표시

| 게임 | 방식 |
|---|---|
| 원신 | 무기 자체는 HUD 미표시(메뉴). 대신 **파티 4캐릭 카드(좌상)** 로 전환 |
| 명조 | **공명자 3명 스위치(우측 세로)** — 무기가 캐릭터에 내장. 활성 캐릭 강조 |
| ToF | **무기 2~3개 아이콘(우하단)** + 전환. 무기별 스킬 — **RelicFairy와 가장 유사** |
| ZZZ / PGR | **에이전트 3명 스위치**(우하단/우측), 활성 강조 + 교체 쿨 |

**🟢 공통점**
- 전투 HUD에 **장착 무기를 상시 크게 진열하지 않음**(상세는 메뉴).
- **전환(스위치)이 있으면** 슬롯을 세로/가로로 두고 **활성만 강조**(하이라이트·확대·발광).
- 활성/비활성, 교체 가능 여부를 **한 눈에** 구분(테두리·명도).

**→ RelicFairy 적용**: 무기 2슬롯(근/원)은 **활성만 금테+확대**로 강조. 크게 진열하지 말고 코너에 절제.

---

## 2. 고유 캐릭터 기술 (시그니처 / 궁극)

| 게임 | 방식 |
|---|---|
| 원신 | **원소폭발(Q)** = 큰 원형 버튼 + **에너지 충전 링**. 충전 완료 시 발광 |
| 명조 | **공명 해방(궁극)** = 협주 게이지 충전 후 발동, 강한 연출 |
| 붕괴3rd/PGR | **궁극기** = 캐릭터 초상+게이지, 발동 시 화면 컷인 |
| ZZZ | **얼티밋/연계** = 게이지 만땅 시 아이콘 발광 |
| 니케 | **버스트 스킬** = 단계별 게이지, 발동 순번 강조 |

**🟢 공통점**
- 시그니처/궁극은 **가장 크고 발광**, 나머지 스킬보다 시각 위계 위.
- **충전 게이지/에너지 링**으로 "준비도"를 상시 표시(원형 링 또는 전용 바).
- 준비 완료 = **발광/맥동/색 변화**로 강조(발동 타이밍 유도).

**→ RelicFairy 적용**: **Q(유물 시그니처)** = 전용 포드(금) + **체력바 아래 아이덴티티 게이지 바**로 준비도. 준비/절정 시 맥동·플래시(이미 구현).

---

## 3. 장비 스킬 2개 (E · R)

| 게임 | 방식 |
|---|---|
| 원신 | 우하단 **기본공격(대) + 원소스킬 E + 폭발 Q** 삼각/아크 배치. E·Q에 **쿨다운 Radial** |
| 명조 | 우하단 **기본·공명스킬·에코·해방** 클러스터. 각 쿨/충전 표시 |
| ToF | 무기별 **스킬 버튼 + 회피/차징**, 쿨 Radial |
| ZZZ/PGR | 우하단 **스킬 버튼 2~3 + 회피/패링** |

**🟢 공통점**
- 스킬 = **우하단 클러스터(아크/행)**. 엄지·커서 동선.
- **쿨다운 = 원형 Radial 오버레이 + 숫자**.
- **키/버튼 라벨** 병기. 아이콘은 **원형/둥근 사각** 슬롯.

**→ RelicFairy 적용**: **E·R** = 무기 포드(청), 쿨 Radial + 키 라벨. **R(궁극) 가장 크게**.

## 4. 서약 (로그라이크 축복 / 각인)

| 게임 | 방식 |
|---|---|
| 하데스류 로그라이크 | 획득 축복 = **코너 아이콘 리스트**, 상세는 호버/메뉴 |
| 원신 | 심연/이벤트 버프 = **좌측/상단 아이콘 리스트**(상시 최소) |
| ZZZ 로그류 모드 | 획득 각인 **아이콘 스택**, 개수만 상시 |
| 공통 가챠 | 성유물/음성함 등 **빌드는 HUD 미표시**(메뉴). 런 한정 버프만 아이콘 |

**🟢 공통점**
- 런/빌드 계약은 **작은 아이콘 리스트(코너)** — 상시엔 존재만, **상세는 호버/메뉴**.
- 개수가 많아지면 **그리드/스크롤**, 중요한 것만 강조.
- 공간 절약: 텍스트 최소, **아이콘 우선**.

**→ RelicFairy 적용**: 서약 = **좌측 세로 아이콘 리스트**(상세 호버). 상시 존재만, 화면 안 잡아먹게.

---

## 5. 버프 / 디버프

| 게임 | 방식 |
|---|---|
| 원신 | 상태/원소부착 = **작은 아이콘 + 타이머**, 캐릭/적 근처 |
| 명조 | 버프/디버프 = **좌측 아이콘 행 + 잔여 게이지** |
| 붕괴3rd/PGR | 자버프 **아이콘 + 스택 숫자 + 타이머 링** |
| 공통 | 디버프는 **적 위/자신 근처**, 색으로 이로움/해로움 구분 |

**🟢 공통점**
- **작은 아이콘 + 잔여시간(링/바) + 스택 숫자**의 3요소.
- **좌측 또는 캐릭터 근처** 배치(주변시야). 이로움/해로움 **색 구분**.
- 움직이는 잔여 게이지로 **만료 임박 감지**(주변시야 모션).

**→ RelicFairy 적용**: 버프 = **좌측 그리드**(아이콘+스택) + 게이지 분리. 유물 패시브=금 첫셀.

## 공통 원칙 요약 (전 게임 관통)
1. **중앙 시야 비움** — 정보는 외곽(모서리)으로.
2. **스킬 = 우하단 클러스터** + 쿨 Radial + 키 라벨.
3. **시그니처/궁극 = 최대·발광 + 충전 게이지/링**.
4. **HP·핵심 리소스 = 하단중앙/캐릭터 근처**.
5. **미니맵 = 좌상단**, 골드/재화 = 우상단.
6. **버프 = 좌측/근처 아이콘 + 타이머 + 스택**.
7. **빌드/계약(서약) = 코너 아이콘 리스트**, 상세는 호버.
8. **활성/준비 상태 = 색+형태+발광** 이중부호화.

## RelicFairy가 이미 부합하는 지점
- HP 하단중앙 · 스킬 우하단 2포드 · 유물 시그니처 게이지 바 · 버프 좌측 · 서약 좌측 리스트 · 미니맵 좌상 · 골드 우상 · 활성 무기 강조 · 궁극(R) 강조 — **컨벤션과 일치**.
- **차별점(정체성)**: 유물별 **전용 아이덴티티 바**(가웨인 정오 주기 / 랜슬롯 광기 게이지)로 캐릭터 개성을 상시 시각화 — 원신 에너지링·명조 협주게이지의 "리소스 게이지" 컨벤션을 유물 테마로 확장.
