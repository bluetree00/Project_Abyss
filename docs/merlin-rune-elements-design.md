# 멀린 룬 그리드 — 속성 기획안 (2026-06-05 수령)

> 출처: 사용자 기획안. 멀린 룬 그리드의 6속성 × 4단계 효과 정의.
> 관련: 보드 레이아웃 = 132칸 육각(칸/블록 사각, 인접 4방향), 코드 중앙화 = ElementDef.

## 핵심 구조 변경

**단계 판정 = "해당 속성 그리드를 얼마나 채웠는지(%)".** 기존 클러스터 셀 수 임계값(`clusterSize >= N`)이 아니라 **점유율 기반 4단계**:

| 단계 | 채움 % |
|---|---|
| 1단계 | 30% |
| 2단계 | 50% |
| 3단계 | 70% |
| 4단계 | 100% |

- 채움% = (해당 속성 점유 셀 수) / (해당 속성 전체 셀 수). `MerlinRuneHexGridView.GetZoneOccupiedCounts/GetZoneTotalCounts`로 산출 가능.
- 단계는 **누적**(상위 단계 도달 시 하위 단계 효과 유지 — 상위가 하위를 전제로 설계됨).

## 6속성 (명칭 변경: 번개→전기, 독→풀)

| 속성 | 컨셉 한 줄 |
|---|---|
| 불 Fire | 공격할수록 불이 붙고 단계가 오를수록 더 크게·오래 탄다 (화염 피해 증폭) |
| 얼음 Ice | 느림→정지→취약→확산. 정지 상태를 최대한 활용 |
| 전기 Electric | 빠른 공격 리듬 유지로 자기 강화 루프. 전기 단독 완결 |
| 풀 Grass | 적중 자리에 독안개 장판 생성, 겹치면 독성 중첩·연결되어 거대 독무 필드 |
| 빛 Light | 치명타로 빛이 쌓이고 터지며 잠깐 무적. 장판 위 치명타 가속 루프 |
| 어둠 Dark | 맞을수록 강해진다. 게이지 축적 → 암흑/랜덤 버프 |

### 불 Fire
- **1 잔불(30%)**: 공격 적중 시 공격력 8% 화염 피해 추가.
- **2 점화(50%)**: 잔불 5회 발동마다 점화 부여 — 3초간 초당 공격력 16% 피해 3회.
- **3 폭염(70%)**: 점화 상태 적 공격 시 화염 피해량 +35%.
- **4 작열(100%)**: 점화 만료 시 폭발 — 남은 DoT 합산 × 공격력 150% 광역.

### 얼음 Ice
- **1 서리(30%)**: 적중 시 적 이동속도 -12%, 3초 (중첩 최대 -24%).
- **2 빙결(50%)**: 서리 2중첩 적에 스킬 적중 시 빙결 1.5초 (내부쿨 10초).
- **3 분쇄(70%)**: 빙결 적 공격 피해 +30%, 빙결 해제 시 방어력 -20% 5초.
- **4 빙하 연쇄(100%)**: 빙결 해제 시 빙하 낙하 공격력 150% 광역 + 서리 1중첩 부여.

### 전기 Electric
- **1 정전기(30%)**: 공격속도 +10%. 적중 시 정전기 스택+1, 스택당 공속 +1% (10초, 최대 10).
- **2 방전(50%)**: 스킬 사용 시 정전기 스택 전량 소모 — 스택당 공격력 4% 번개 피해 즉발.
- **3 감전(70%)**: 방전 시 감전 부여 — 1초 마비, 스택당 감전 지속 증가(최대 3초). 감전 중 공속 +8%.
- **4 과부하(100%)**: 공격 시 체인 라이트닝 — 주변 최대 2명에게 50% 피해, 없으면 같은 적 2회.

### 풀 Grass (독안개)
- **1 독안개 살포(30%)**: 적중 자리에 독안개 10초(최대 3개). 안에 머무는 적 초당 공격력 4% 독 피해.
- **2 독안개 강화(50%)**: 장판 크기 +50%. 겹침 영역 독 피해 +50%.
- **3 독안개 간파(70%)**: 장판 크기 +50%, 독 피해 시 최대HP 0.1% 회복. 겹침 3초 이상 몬스터 공격력 -20%.
- **4 독무 지배(100%)**: 장판끼리 닿으면 전체가 겹침 판정. 장판 내 적 독 피해 ×2, 회복 0.2%, 집중력분산 30%, 보스 받피 +15%.

### 빛 Light
- **1 광채(30%)**: 치명타 시 광채 스택+1(최대 10). 스택당 치확 +1%.
- **2 광폭발(50%)**: 광채 10스택 소모 — 전방 원뿔 공격력 150% 폭발, 스택 초기화.
- **3 성역(70%)**: 광폭발 자리에 빛 장판 3초(최대 1). 장판 위 치명타 시 광채 +3.
- **4 빛의 장판(100%)**: 장판이 캐릭터 추종. 장판 위 공격 치확 +20%, 치피 +30%.

### 어둠 Dark
- **1 잠식(30%)**: 피격 시 어둠 게이지 +10, 적중 시 +3 (최대 100). 게이지 비례 공격력 최대 +15%.
- **2 암흑 해방(50%)**: 게이지 100 달성 시 5초 암흑 — 공격력 +25%, 받피 -15%.
- **3 그림자 잔상(70%)**: 암흑 중 적중 시 동일 공격 40% 피해를 0.5초 후 추가.
- **4 심연 각성(100%)**: 게이지 달성 시 랜덤 버프 부여 (아래 버프 풀에서 추첨).

#### 어둠 4단계 랜덤 버프 풀
- 공격력 +1 / +15 / +20 / +30 / +100 %
- 공격속도 +1 / +20 / +30 / +50 / +100 %
- 스킬 쿨타임 -1 / -15 / -30 / -50 / -100 %
- 모든 스탯 +1 / +15 / +50 / +100 / +500 %
- 체력회복 1 / 10 / 30 / 50 / 100 %
- 주변 몬스터 방어력 감소 1 / 10 / 20 / 30 %
- 받는 데미지 감소 1 / 10 / 20 / 30 / 100 %

## 분석 — 미해결/결정 필요

1. **단계 판정 모델 전환**: `clusterSize >= threshold` → `occupied/total >= tier%`. ZoneClusterCalculator(연결 클러스터) 가 단계 판정에 더 이상 쓰이지 않을 수 있음. **연결성이 단계에 영향을 주는지, 순수 점유율인지 확정 필요.**
2. **CENTER(+) 16칸 용도 미정**: 신 기획안에 중심 구역 언급 없음. 속성에 속하지 않아 채움%에 미포함. 보너스 유지/폐기/재정의 결정 필요.
3. **스키마 재설계**: 효과당 파라미터가 3슬롯(value/value2/value3) 초과(예: 불2 = 5회/3초/16%/3회). effect_type을 (속성,단계)별 고유키로 두고 파라미터 인코딩 확장 필요.
4. **전투 메커니즘 대량 신설**: 24개 효과 대부분이 기존 12종 핸들러로 표현 불가. DoT/점화/빙결/정전기 루프/장판(필드) 생성·겹침/치명 스택+무적/게이지+랜덤버프 등 — 전투·상태이상·필드·VFX 시스템 신규. 다단계 구현 필요.
5. **라이브 vs 래치**: 단계는 배치/제거에 따라 실시간 재계산(편집 중 단계 변동) 가정.

## 구현 단계(제안)
1. **틀 전환**: 단계 판정 % 기반으로 변경 + 스키마 재설계 + 단계 상태 노출(UI 4단계). (코드+데이터)
2. **상태이상/필드 인프라**: 적 상태이상(점화/서리/빙결/감전/중독), 장판 필드 시스템, 플레이어 게이지/스택 공통 틀.
3. **속성별 수직 슬라이스**: 한 속성(예: 불) 1→4단계 완성 후 나머지 확장.
