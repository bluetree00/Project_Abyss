# RelicFairy — "한 판 더" 후크 / 메타 프로그레션 설계 가이드

작성일: 2026-06-03
방법: 로그라이크 리텐션·메타 프로그레션·세션 심리 리서치 + RelicFairy 적용 설계.
사례·근거: Hades, Dead Cells, Rogue Legacy, Slay the Spire(Ascension), Risk of Rain, Binding of Isaac, 세션 심리 연구(Zeigarnik/Ovsiankina).

## 0. 핵심 결론
1. "한 판 더"의 핵심은 기억이 아니라 재개 욕구다. 통념인 Zeigarnik 효과는 2025년 메타분석에서 부정됐고, 살아남은 건 Ovsiankina 효과(중단된 일을 재개하려는 욕구). 설계 함의: 다음 목표를 코앞에 노출 + 재시작 마찰 제거.
2. 명작들의 황금률: "해금 = 난이도 하락이 아니라 선택지 확장(adds options, not power)". 영구 파워 인플레는 런 내 선택의 무게를 죽인다.
3. 패배를 진전으로 만드는 Hades식 4대 장치: 메타 통화 / 내러티브 진행 / 다음 해금 노출 / "No Game Over".
4. RelicFairy 적용 결론: 재미축이 Discovery·Expression(룬 퍼즐)이라 파워형 메타는 상극. 선택지 확장형 + 내러티브형 + 코스메틱형으로 가야 정합.

## 1. 리서치 종합
### 세션 심리
- Ovsiankina > Zeigarnik: 중단된 활동을 재개하려는 충동. 세션 종료 지점에 "다음에 할 것"이 명확히 보이고 재시작이 즉각적이게.
- 가변 보상 스케줄(절제), 재시작 마찰 최소화.
### 메타 프로그레션 유형
- 선택지 확장형(해금): 런 다양성↑, 선택의 무게 유지. (Dead Cells, Slay the Spire)
- 파워형(영구 능력치): 진입장벽 완화하나 선택의 무게·도전 약화(인플레). (Rogue Legacy)
- 내러티브형: 패배가 진전, 정서 후크. 콘텐츠 제작비 큼. (Hades)
- 숙련형/코스메틱형: 인플레 없음.
### 밸런스 함정
- 파워 인플레, 그라인드 게이팅, 가챠/도파민 루프화.
### 세이브/일시중단
- suspend-on-exit는 세션 접근성을 높여 반복 플레이를 크게 돕는다.

## 2. RelicFairy 적용 설계안
- 메타 유형: 파워형 회피, 선택지 확장형(메인)+내러티브형(정서)+코스메틱형(보조) 결합.
- 세계관 결합: 메타 통화="영혼 파편", 베이스캠프=멀린의 복원 무대(패배=영혼 한 조각 복구로 재프레이밍), 다음 해금 노출로 Ovsiankina 자극.
- 서약(Covenant) = Slay the Spire의 Ascension 역할: 영구 파워 없이 선택형 상승 난이도로 도전 재공급.
- 세이브/일시중단(suspend-on-exit) 1순위: 런 상태(visitCount/경로/RNG/시너지/인벤토리/룬 그리드) 직렬화.

## 3. 도입 로드맵
- Phase 0 — 코드 확인: 현 메타 구현 정도, 통화 존재, ApplyRunResultAsync 스키마, 런 평균 길이.
- Phase 1 — MVP: suspend-on-exit 세이브 / 메타 통화 / 베이스캠프 해금 거점 / 패배 후 진전 연출 + 다음 해금 노출.
- Phase 2 — 심화: 룬 그리드 깊이 해금, 서약 Ascension식 확장.
- Phase 3 — 내러티브 확장: 아서왕·영혼 복구 서사.

## 4. 밸런스 가드레일 ("해금 = 선택지 확장" 체크리스트)
1. 새 해금은 파워가 아니라 옵션을 추가하는가?
2. 해금 후에도 런 내 선택의 무게가 유지되는가?
3. 콘텐츠가 그라인드 뒤에 게이팅되지 않는가?
4. 통화 획득이 플레이 자체에서 자연 발생하는가?
5. 도전(서약/상승)이 파워 없이 재공급되는가?
6. 패배가 진전으로 프레이밍되는가?
7. 다음 목표가 세션 종료 시점에 노출되는가?

## 5. 과설계/범위 초과 경계
- 영구 파워 인플레(금지), 그라인드 게이팅/가챠화, 과도한 내러티브 제작비, 메타가 코어를 대체하는 것.
