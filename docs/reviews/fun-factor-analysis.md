# RelicFairy — 게임 재미 요소 분석 + 개선점

작성일: 2026-06-03
방법: 재미(fun/enjoyment) 학술·이론 프레임워크 리서치 + RelicFairy 현재 디자인 매핑.
프레임워크: Flow(Csikszentmihalyi), MDA + LeBlanc의 8 kinds of fun, 자기결정이론(SDT)·PENS, 플레이어 동기 모델(Bartle/Yee/Quantic Foundry), Juiciness/게임필, 로그라이크 재미, 보상 심리.

## 0. 핵심 결론
RelicFairy의 재미 정체성은 "Challenge × Discovery × Expression" 삼각형이다.
- Challenge — 액션 전투 + 빌드 시너지 최적화
- Discovery — 절차생성 런 가변성 + 시너지/유물 조합 탐색
- Expression — 멀린 룬 헥사 그리드 퍼즐(공간 배치형 빌드 표현, 로그라이크에서 드문 차별점)
가장 큰 공백은 "한 판 더" 후크(메타/세이브)와 타격 피드백(Juiciness). 차별화(룬 퍼즐·서약)를 더 살리는 방향이 ROI 높음.

## 1. 재미 이론 요약
- Flow: 도전-숙련 균형, 명확한 목표, 즉각 피드백 → 몰입.
- 8 kinds of fun: Sensation/Fantasy/Narrative/Challenge/Fellowship/Discovery/Expression/Submission. 정체성 = 어느 축을 미느냐.
- SDT/PENS: 자율성·유능감·관계성 충족이 내적 동기.
- 동기 모델(Bartle/Yee/Quantic Foundry): 플레이어마다 추구 가치 다름.
- Juiciness: 풍부한 출력 피드백이 같은 메커닉도 더 재미있게 인식(단 과증폭은 역효과).
- 로그라이크 재미: 메타 프로그레션, 런 가변성, "한 판 더", 리스크-리워드, 빌드 다양성.
- 보상 심리: 가변 보상 + 성취·호기심.

## 2. 현재 재미 요소 진단(강점)
- Expression(차별점): 룬 헥사 그리드 퍼즐 — 빌드를 손으로 조립하는 표현 재미. 공간 퍼즐형 빌드는 드문 차별화.
- Challenge × Discovery: 성장 3축(유물·무기·룬 시너지) 조합 최적화 + 절차생성 가변성.
- 자율성(SDT): 유물·무기 선택 + 서약 3택이 런 초반 자율성·리스크리워드.
- Fantasy: 아서왕 동화풍 + "영혼 빙의" 콘셉트.
- 잠재 강점: 룬+서약+유물 교차 시너지로 빌드 다양성 폭발 가능.

## 3. 재미 공백/개선점
- 로그라이크 "한 판 더": 메타 프로그레션[확인 필요]+세이브 미구현 → 영구 해금·일시중단(해금=선택지 확장).
- Flow(즉시 피드백): 타격 출력단 얇음 → Juiciness 보강(히트스톱·플래시·넘버).
- Flow(난이도 곡선): 적 조합·엘리트 단순 → 서약 기반 선택형 난이도 + 적 다양화.
- 유능감: 빌드 효과 즉각 가시화.
- Narrative: 약함 → 경량 서사(유물 사연·멀린 대화).
- Discovery 깊이: 룬 시너지 깊이 강화.
- Sensation/Fantasy: 유물별 외형 차별화(오라→외형) 연결.
- Fellowship: 멀티 없음 → 의도적 공백 권장(코어와 정렬 약함).

## 4. 우선순위 백로그
- P0: "한 판 더" 후크(메타+세이브). 밸런스 위험은 "해금=선택지 확장" 원칙.
- P1: 타격 피드백/Juiciness(퀵윈, 과증폭 금지).
- P2: 서약 기반 선택형 난이도 + 적 조합/엘리트/방 유형 다양화.
- P3: 룬 시너지 깊이. P4: 경량 서사. P5: 유물별 외형.

## 5. 과설계 경계
멀티(Fellowship) 의도적 공백, 메타 과다(파워 인플레), Juiciness 과증폭, 서사 과다. 핵심 원칙: 세 차별 자산(룬 퍼즐·서약·유물 빙의)을 더 깊게 미는 것이 새 축 추가보다 ROI 높음.
