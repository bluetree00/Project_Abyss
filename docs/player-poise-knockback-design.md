# 플레이어 포이즈(아머치) · 넉백 / 날아감 기획서

작성 2026-07-11 · 상태: **기획 확정, 구현 미착수**

---

## 1. 목표

플레이어가 피격당할 때 **매 공격마다 날아가지 않도록** 게이트를 두고, **일정 이상 누적되면 한 번씩 크게 날아가게** 한다.

핵심 아이디어: **포이즈(아머치) 게이지 + 회복**. 별도의 "N초 안에 M대" 카운터를 두지 않는다 — 회복이 붙은 포이즈가 그 규칙을 자동으로 만들어내기 때문이다(§3 참고).

---

## 2. 핵심 모델 — 포이즈 게이지

```
피격
  └─ 현재 포이즈 -= 임팩트치
        ├─ 포이즈 > 0  → 날아가지 않음 (피해 + 기존 피격 피드백만)
        └─ 포이즈 ≤ 0  → 【날아감 발동】
                          ├─ 포이즈 풀 리셋 (초기화)
                          ├─ 넉백 면역 창 시작 (체인 방지)
                          └─ LocoState.Launched 진입 (띄우기 → 공중경직 → 착지)

피격이 끊기면
  └─ 회복 지연 경과 후 → 초당 서서히 회복 (최대치까지)
```

---

## 3. 왜 "아머치"와 "단시간 누적"이 하나로 합쳐지는가

두 아이디어는 별개 시스템이 아니다. **포이즈에 회복을 붙이면 누적 규칙이 저절로 생긴다.**

| 상황 | 포이즈 거동 | 결과 |
|---|---|---|
| 연타로 빠르게 맞음 | 회복이 못 따라감 → 계속 깎임 | **브레이크 → 날아감** ✅ |
| 띄엄띄엄 맞음 | 사이사이 회복 | 안 날아감 ✅ |
| 한 방이 매우 강함 | 임팩트치가 커서 단번에 0 | **즉시 날아감** ✅ |

별도 카운터를 두면 포이즈와 규칙이 **이중화되어 서로 어긋난다**. 튜닝 축도 늘어난다. → **포이즈 단일 모델 채택.**

---

## 4. 수식 · 파라미터

### 임팩트치 (공격 1대가 깎는 포이즈)

```
임팩트치 = 최종피해량 × poiseImpactPerDamage
```

- **피해량 비례** 방식 채택 → **신규 공격 데이터 0**으로 즉시 도입 가능
- 센 공격이 자동으로 더 많이 깎음 (보스 강타 = 1~2대에 브레이크, 잡몹 평타 = 여러 대 필요)
- **최종피해량(경감 후)** 기준 → 방어력이 높으면 포이즈도 덜 깎임 (아머치 개념과 자연스럽게 부합)

### 파라미터 초안

| 항목 | 키 | 초안 | 비고 |
|---|---|---|---|
| 포이즈 최대치 | `maxPoise` | 100 | **스탯**(§6) — 유물/아이템으로 성장 |
| 피해→포이즈 계수 | `poiseImpactPerDamage` | 2.5 | 실제 몬스터 피해량에 맞춰 캘리브레이션 필요 |
| 회복 지연 | `poiseRegenDelay` | 1.5초 | 마지막 피격 후 이만큼 지나야 회복 시작 |
| 회복 속도 | `poiseRegenPerSec` | 40/s | ≈2.5초면 풀 회복 |
| 넉백 면역 | `knockbackImmunity` | 1.5초 | 날아감 직후 — **저글링 방지(필수)** |
| 착지 회복 i-frame | `landingIFrame` | 0.3초 | 착지 직후 즉시 재피격 방지 |

**캘리브레이션 기준:** 일반몹 평타 ≈ 포이즈의 1/4 (4대에 브레이크), 엘리트 강타 ≈ 1/2, 보스 대기술 ≈ 즉시 브레이크.

## 5. `LocoState.Launched` 상태 스펙 (신규)

기존 `LocoState = { Idle, Move, Air, Dodge }` 에 **Launched** 추가. Dodge 상태와 대칭 구조.

| 단계 | 동작 |
|---|---|
| **Enter** | 공격자 반대방향 **수평 임펄스 + 상향 리프트** 적용 / 진행 중 공격·스킬 **캔슬**(`ActState.None`) / 입력·이동 잠금 / 피격 애니 재생 |
| **Update** | 포물선 체공 → **착지 감지**(`IsGrounded` && 하강 중) → 짧은 착지 경직 → Idle/Move 복귀 |
| **Exit** | 제어 복원 / 착지 i-frame 부여 |

**기반은 이미 확보됨:** `PlayerController.ApplyKnockback(force, duration)` + `IsKnockback` 이 `DefaultMoveAbility.Move()` 를 스킵시켜 **임펄스가 이동 코드에 덮이지 않는다**. 여기에 상향 성분 + 착지까지 유지 + 상태 라이프사이클을 얹는다.

---

## 6. 스탯 연동

`PlayerRuntimeStats` 에 **포이즈(maxPoise)** 추가 → 유물 / 아이템 / 서약으로 증가.

- "**버티는 빌드**"가 성립 → 빌드 다양성 확보
- 기존 스탯 파이프라인(`Recalculate`)에 얹으므로 신규 구조 최소

---

## 7. 예외 — 관통 공격 (`ignorePoise`)

보스 대기술처럼 **연출상 반드시 날려야 하는 공격**은 포이즈를 무시하고 즉시 날아감 발동.

- 플래그 **1개**면 충분 (`ignorePoise: bool`)
- 이 경우에도 **포이즈는 초기화**되고 넉백 면역은 정상 적용 (체인 방지는 예외 없음)

---

## 8. ⚠️ 체인 방지 (필수 — 옵션 아님)

날아감 직후 보호가 없으면 **무한 저글링으로 즉사**한다. 반드시 포함:

1. **넉백 면역 창** (1.5초) — 이 동안 포이즈가 깎이지 않고 재발동 불가 (피해는 정상 적용)
2. **착지 i-frame** (0.3초) — 착지 직후 무적

---

## 9. 필요 리소스

| 항목 | 상태 |
|---|---|
| 플레이어 **피격/공중피격 애니** | ❌ **전무** (컨트롤러에 Hit/Damaged/Knockdown 상태 자체가 없음) |
| 임시 대안 | `JumpBlend`(공중 포즈) 재사용 → 메커니즘 검증은 가능, "맞고 날아가는" 느낌은 약함 |

→ **메커니즘 먼저 구현 → 피격 애니 소싱 후 스왑** (대검 무브셋과 동일 방식) 권장.

---

## 10. 구현 단계 (예정)

| Phase | 내용 | 애니 의존 |
|---|---|---|
| **1** | 포이즈 게이지(최대치·감소·회복·초기화) + 스탯 노출 | 없음 |
| **2** | `LocoState.Launched` 신설 (띄우기 → 공중경직 → 착지) + 피격 경로 배선 | 임시 클립 가능 |
| **3** | 체인 방지(넉백 면역 + 착지 i-frame) | 없음 |
| **4** | 관통 공격 `ignorePoise` 플래그 | 없음 |
| **5** | 피격 애니 스왑 + 밸런스 캘리브레이션 | **소싱 대기** |

## 11. 미결 / 튜닝 대상

- `poiseImpactPerDamage` 계수 — 실제 몬스터 피해량 확인 후 캘리브레이션
- 포이즈 게이지 **UI 표시 여부** (숨김 / 피격 시에만 노출 / 상시)
- **몬스터 포이즈**로의 대칭 확장 — 현재 몬스터는 *모든* 피격에 `GetHitState`(경직) 진입. 동일 모델 적용 가능하나 **이번 범위 밖**
