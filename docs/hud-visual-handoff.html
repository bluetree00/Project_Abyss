02

형태 언어

글래스 패널

반투명 다크(32~55%) + 상단 하이라이트 라인 + 하단 그림자. 원신 카드·명조 패널 질감. 배경은 항상 비침.

얇은 금장 테두리

1~2px 골드 라인 + 코너 필리그리(명조식 절삭 코너). 유물=금, 무기=청으로 출처를 색으로 즉시 구분.

소프트 글로우

활성·절정 시 외곽 블룸. 색+형태 이중부호화(WCAG 1.4.1) — 색맹에도 프레임 형태로 구분.

위계

스킬 > 무기 > 액티브 순 크기. 궁극(R)이 가장 큼. 밝기·글로우로 시선을 스킬에 모음.

전달 형식 · 네이밍

형식

PNG(투명, @2x). 9-slice 항목은 경계 px 표기. 상태별 파일 또는 스프라이트시트 + 프리뷰.

화이트 마스터

색이 코드 tint인 항목(HP·유물 fill·글로우)은 무채색/화이트로 제작 — 코드가 색을 입힘.

네이밍

hud_<영역>_<요소>_<상태>.png (예: hud_pod_relic_active.png).

우선순위

P0(정체성: 포드·유물바·HP) → P1(무기·버프) → P2(주변·연출) → P3(리터치).
