# RelicFairy — 전체 UI 디자인 의뢰 문서 (대중성/서브컬처 레퍼런스)

> **전제**: 현재 게임의 **모든 UI 리소스는 임시**(프로그래머 아트/기본 스프라이트). 본 문서는 **모든 UI에 통일된 디자인을 적용**하기 위한 디자이너 의뢰서다.
> **목표**: 서브컬처(가챠/액션) 주류 컨벤션을 폭넓게 참고해 **대중성(mass appeal)** 있는 정갈·화려한 UI. 레이아웃/기능은 확정, **아트만 제작→스왑**.
> **정체성**: 아서왕 동화(양피지·유물) × 가챠 폴리시(다크 글래스·골드). 유물=금, 무기=청.

## 2. 대중성 서브컬처 레퍼런스 (광범위 스캔)

> 조사: 원신 · 명조 · 붕괴3rd · 붕스(HSR) · 퍼니싱 그레이레이븐 · 젠레스 존 제로(ZZZ) · 토워 오브 판타지 · 니케 · 하데스(로그라이크). **공통 대중 컨벤션**만 추출.

| UI 카테고리 | 대중 컨벤션(공통) | 대표 참고 |
|---|---|---|
| **HUD** | 중앙 비움 · 스킬 우하단 · 궁극 크게+게이지링 · 미니맵 좌상 · 버프 좌측 | 원신·명조 (별도 문서 `hud-*`) |
| **모달/팝업** | 화면 dim + **중앙 다크 글래스 카드** + 골드 헤더 + 본문 + 하단 CTA. 등장=페이드+스케일 | 원신·HSR 팝업 |
| **선택창**(서약/보상/무기) | **3택 카드 병렬** + 등급 테두리색 + 호버 상세 + 선택 강조. 하데스 축복 UI 표준 | 하데스·ZZZ 로그 |
| **획득 연출**(아이템) | **등급별 색광 리빌** — 카드 줌/플립, 레어=골드·무지개 파티클, 사운드 싱크 | 가챠 리빌 공통 |
| **결과창**(클리어) | 등급 스탬프·별점 + 보상 나열 + 통계, 파티클/컷 연출 | 원신·HSR 결산 |
| **인벤/그리드** | 슬롯 그리드 + **등급 테두리색** + 드래그 + **우측 정보 패널** | 원신 배낭·PGR |
| **상점** | 카드 리스트 + 가격 리본 + 리롤 버튼 + 재화 우상. 정갈한 격자 | 원신 상점 |
| **로비/메인** | 캐릭터 스탠딩(좌/중) + **메뉴 리본**(우/하) + 재화 상단 | 원신·명조 메인 |
| **월드 HP** | 적 위 얇은 바 + 이름, 보스=상단 대형 바 + 페이즈 눈금 | 공통 |

### 등급 색 체계 (아이템·서약·무기 — 가챠 표준, 대중성 핵심)
| 등급 | 색 | HEX |
|---|---|---|
| 일반 | 회색 | `#8E8B98` |
| 고급 | 초록 | `#4CD159` |
| 희귀 | 청색 | `#5AA9FF` |
| 영웅 | 보라 | `#B265FF` |
| 전설 | 금색 | `#FFCC4D` |

→ 슬롯 테두리·카드 배경광·획득 리빌 색을 이 체계로 통일하면 **한눈에 가치 인지**(대중 게이머 학습된 코드).

## 3. 통합 디자인 시스템 (전 UI 공통 언어)

**팔레트**
- 그라운드: 다크 인디고차콜 `#13121A` / 패널 `#1B1926` (반투명 글래스 32~62%)
- 프라이머리 **골드 `#FFCC4D`**(유물·강조·프레임) / 세컨더리 **청 `#73B3FF`**(무기)
- 텍스트: 양피지 잉크 `#ECE6D8` / 뮤트 `#9A93A6`
- 시맨틱: 초록/노랑/빨강(HP) · 보라 `#C74DFA`(절정)

**타이포**
- 디스플레이=세리프(아서왕 스토리북 톤) · UI=산세리프 · 데이터=모노. 한글은 정갈한 고딕(현재 NotoSansKR — Regular 재생성 권장).

**컴포넌트 라이브러리**(전 UI 재사용)
- 글래스 패널(9-slice) · 골드/청 필리그리 프레임 · **등급 테두리** · 라운드 슬롯 · Radial 쿨다운 · 소프트 글로우 · 골드 CTA 버튼 · 재화 리본 · 카드(선택/획득).

**모션**
- 모달=페이드+스케일(0.15s) · 획득=색광 리빌 · 호버=글로우 · `prefers-reduced-motion` 존중. 과함 지양(정갈 우선).

## 4. 요소별 디자인 의뢰 (방향 + 레퍼런스)

| UI | 현재(임시) | 목표 방향 | 레퍼런스 |
|---|---|---|---|

| 상점 | 매대 | 카드 격자+가격 리본+리롤+재화 상단 | 원신 상점 |
| 무기 모루 | 팝업 | 무기 카드(근/원)+스탯+스킬 미리보기 | 무기 강화 UI |

| 인벤/보관함 | 기본 슬롯 | 등급 테두리 슬롯+우측 상세 | 원신 배낭 |

## 5. 제작·전달 가이드
- **형식**: PNG(투명, @2x). 9-slice 경계 명시. 상태별 파일/시트 + 프리뷰.
- **색 tint 항목**(HP/게이지/등급광)은 **화이트 마스터** — 코드가 색 입힘.
- **네이밍**: `ui_<화면>_<요소>_<상태>.png` (예: `ui_shop_card_legendary.png`).
- **우선순위**: **P0**(HUD·대화·서약선택·아이템획득·상점·모루·룬그리드) → P1(결과·보상·각성·보스HP·로비·인벤) → P2(교체·토스트·오버레이·미니맵).
- **일관성**: §3 컴포넌트 라이브러리를 먼저 확정 → 전 UI가 같은 부품 재사용.
