# HUD 비주얼 핸드오프 — 리소스 제작 스펙 (명조/원신 톤)

> 목적: 현재 코드로 구현된 전투 HUD의 **레이아웃·좌표는 확정**. 디자이너는 이 문서의 **톤·리소스 스펙**에 맞춰 아트 에셋(프레임/바/아이콘/글로우)만 제작하면 엔지니어가 스왑한다.
> 기준 해상도: **1920×1080** (Canvas Scale With Screen Size, Match 0.5). 좌표는 앵커 기준 px.
> 참고 톤: **원신(Genshin) + 명조(Wuthering Waves)** — 어두운 글래스 패널 + 얇은 금장 테두리 + 부드러운 글로우 + 코너 필리그리.

## 2. 명조/원신 비주얼 톤

### 2-1. 색 팔레트 (코드 확정값 — 아트가 이 색에 맞게 tint/무채색 제작)
| 용도 | HEX | RGB | 의미 |
|---|---|---|---|
| **유물(Relic) 금** | `#FFCC4D` | (1.00, 0.80, 0.30) | 유물 정체성 — 포드/패시브/게이지 |
| **무기(Weapon) 청** | `#73B3FF` | (0.45, 0.70, 1.00) | 장비 스킬 — 포드 |
| HP 가득(초록) | `#4CD159` | (0.30, 0.82, 0.35) | |
| HP 절반(노랑) | `#F2C733` | (0.95, 0.78, 0.20) | |
| HP 위험(빨강) | `#E63836` | (0.90, 0.22, 0.20) | |
| 광기(랜슬롯) | `#8C3733`→`#F53329` | 붉은강도↑ | 스택 비례 |
| 광기 MAX/심판 | `#C74DFA` | (0.78, 0.30, 0.98) | 보라 |
| 빈틈 | `#59506B` | (0.35, 0.30, 0.42) | 어두운 보라회 |
| 정오(가웨인) | `#FFD940` | (1.00, 0.85, 0.25) | 밝은 금 |
| 충전/각인 | `#B89430`→`#FF9E2E` | 어두운금→주황 | |
| 패널 배경(글래스) | `#000000` @ 32~55% | 반투명 검정 | Backdrop/트랙 |

### 2-2. 형태 언어 (Form Language)
- **글래스 패널**: 반투명 다크(32~55%) + 미세 상단 하이라이트 라인 + 하단 그림자. 원신 카드/명조 패널 질감.
- **얇은 금장 테두리**: 1~2px 골드 라인 + 코너에 작은 **필리그리 장식**(명조식). 유물=금, 무기=청.
- **부드러운 글로우**: 활성/절정 시 외곽 소프트 블룸(색+형태 이중부호화, WCAG 1.4.1 — 색맹 대응).
- **아이콘 인셋**: 슬롯 안 아이콘은 15% 여백(현재 SkillIcon 앵커 0.15~0.85).
- **모서리**: 라운드 4~8px, 명조식 각진 절삭 코너 혼용 가능.

## 3. 제작 리소스 목록 (에셋 스펙)

> 형식: **PNG(투명)**, 9-slice 가능 항목은 **9-slice 경계 명시**. 2배 해상도 권장(@2x). 상태별로 별 파일 또는 스프라이트시트.

### 3-1. HP 바 (얇은 모던)
- `hp_track.png` — 520×16, 9-slice(좌우 캡). 다크 글래스 트랙 + 얇은 금테.
- `hp_fill.png` — 단색 화이트(코드가 초록/노랑/빨강 tint) 또는 그라디언트 마스크. 좌→우 채움.
- (선택) `hp_endcap.png` — 좌우 보석 캡(원신식). 늘어나지 않는 고정 장식.
- 상태: 색은 코드 tint. 디자이너는 **무채색/화이트 마스터** 제공.

### 3-2. 유물 아이덴티티 바 (체력바 아래)
- `relic_bar_track.png` — 360×14, 9-slice. HP보다 얇고 은은.
- `relic_bar_fill.png` — 화이트 마스터(코드가 유물색 tint + 맥동 글로우).
- (선택) `relic_bar_tick.png` — 단계 눈금(광기 16/31/MAX, 정오 각인80%) 오버레이.

### 3-3. 스킬 포드 (유물 Q / 무기 E·R) — **핵심**
- `pod_frame_relic.png` — 금색 포드 프레임, 9-slice, 코너 필리그리. 안쪽 Q 슬롯 원형 홈.
- `pod_frame_weapon.png` — 청색 포드 프레임, 9-slice. E·R 2슬롯(R이 더 큼).
- `skill_slot_ring.png` — 스킬 슬롯 원형 링(쿨다운 Radial 오버레이용, 별도).
- `skill_cooldown_overlay.png` — Radial360 필(반투명 검정).
- `pod_glow_relic/ weapon.png` — 절정/맥동 시 외곽 소프트 글로우(색은 코드).
- 상태: 일반 / **활성(궁극 R 준비)** / 쿨다운. 라벨 "유물"/"무기"·키 Q/E/R은 TMP(코드).

### 3-4. 무기 슬롯 ×2 (좌하단, 현재 무기 강조)
- `weapon_slot_frame.png` — 78×78, 슬롯 프레임(다크+금테).
- `weapon_slot_active.png` — **활성 무기 강조**: 밝은 금테 + 글로우(현재 코드는 Outline+1.15배, 아트로 대체 가능).
- (선택) `weapon_type_icon_*` — 카타나/대검/활/석궁 폴백 아이콘(이미 존재, 리터치만).

### 3-5. 버프 그리드 / 게이지 (좌측)
- `buff_cell.png` — 46×46 셀 프레임(다크 글래스+얇은 테). 유물패시브 첫 셀은 **금 강조 변형** `buff_cell_relic.png`.
- `buff_gauge_bar.png` — 게이지 바(잔여시간).
- 아이콘은 효과별(별도 아이콘셋 — 후속).

### 3-6. 주변 프레임
- `minimap_frame.png` — 136×136 원형/각형 미니맵 테두리(명조식 나침반 톤).
- `panel_glass_9slice.png` — 서약/퀘스트/공용 패널 글래스(9-slice 범용).
- `center_backdrop.png` — 560×106 중앙 하단 반투명 판(그라디언트 페이드 가능).
- `gold_badge.png` — 우상단 골드 프레임(이미 존재 톤 유지).

### 3-7. 상태·연출 (아트 가이드)
| 연출 | 현재 코드 | 아트 제작 |
|---|---|---|
| HP 감소 | 초록→빨강 + 고스트 트레일 | fill 마스터 + (선택)고스트 fill |
| 유물 게이지 맥동 | fill² 비례 외곽 글로우 | `pod_glow`/`relic_bar` 글로우 스프라이트 |
| **가웨인 정오 진입** | 플래시 + 바 펀치 확대 + 빠른 맥동 | 정오 진입 **버스트/링 플래시** 스프라이트 |
| 랜슬롯 MAX(심판) | 보라 전환 | MAX 강조 프레임/글로우 |
| 활성 무기 | 금테 + 1.15배 | `weapon_slot_active` 프레임 |

## 4. 제작 우선순위 & 전달
1. **P0 (정체성)**: 스킬 포드(유물 금/무기 청) · 유물 아이덴티티 바 · HP 얇은 바
2. **P1**: 무기 슬롯(활성 강조) · 버프 셀(유물 금 첫셀) · CenterBackdrop
3. **P2**: 미니맵/서약/공용 패널 글래스 · 정오/심판 연출 스프라이트
4. **P3**: 골드/보스 HP 프레임 리터치

**전달 형식**: PNG(투명, @2x), 9-slice 항목은 경계 px 표기, 상태별 파일 또는 시트 + 프리뷰. 색이 코드 tint인 항목(HP/유물 fill/글로우)은 **화이트 마스터**로.

**네이밍**: `hud_<영역>_<요소>_<상태>.png` (예: `hud_pod_relic_active.png`).
