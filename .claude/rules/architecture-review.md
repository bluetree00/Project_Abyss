# 구조 설계 체크 (새 클래스/시스템 생성 시)

새 클래스, 시스템, 데이터 구조를 설계할 때 구현을 마친 후 반드시 아래를 수행한다:

## 대안 검토 (MUST)
1. 현재 설계의 장단점을 간단히 정리한다
2. 더 나은 대안이 있는지 스스로 검토한다:
   - 더 단순한 구조는 없는가?
   - 기존 프로젝트 패턴과 일관성이 있는가?
   - 확장성과 유지보수성은 충분한가?
   - 불필요한 추상화가 포함되어 있지 않은가?
3. 대안이 있다면 사용자에게 현재 구조와 대안을 비교 제시한다

이 검토는 기존 코드 수정이 아닌 **새 구조 생성** 시에만 적용한다.
