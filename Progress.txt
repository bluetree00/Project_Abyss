Render Mode: 보통 Screen Space - Overlay

Canvas Scaler: Scale With Screen Size

Reference Resolution: 보통 1920 x 1080 (프로젝트 기준으로 통일)

Match: 0.5 (가로/세로 중간)

Graphic Raycaster: 입력 받는 캔버스만 켬(안 받으면 꺼도 됨)

핵심: 프로젝트 전체에서 기준 해상도/Match는 통일해.
캔버스마다 다르면 해상도별 UI 크기 균형이 틀어지기 쉬움.

UI 제작 방식


UI들을 표현할 데이터를 UI 데이터 포멧 클래스에서 여러 영역을 찾아서 연결해두면

사용할 UI가 UI데이터 포멧 클래스에서 필요한 부분만 가져간다로 생각.

이때 만약 플레이어가 01의 장비를 들고있다면 01을 조회해서 사용할 UI를 바인딩해서 가지는것도 가능할듯




우선 캔버스를 기준으로 포멧으로 나누고 진행

조건(WHEN)은 Presenter,
결과(WHAT)는 Provider,
표현(HOW)은 View.


이벤트로 UI를 통제함
