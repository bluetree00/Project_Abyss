## 1. 세계 개요

| 항목 | 내용 |
|---|---|
| **챕터명** | 부패의 숲 (Corrupted Forest) |
| **장벽 테마** | 흑수 (黑水, Corrupted Black Water) |
| **총 맵 크기** | 약 320m × 660m |
| **고도 범위** | +0m (Z1 시작) → +40m (Z26 보스) |
| **존 수** | 26존 |
| **런당 방문** | 12존 (레이어당 1개 선택) |
| **보스** | 그린 나이트 (The Green Knight) |

### 세계 설명

한때 아서왕의 기사들이 순례하던 성스러운 숲. 멀린의 죽음 이후 부패가 번지며 흑수가 땅을 잠식했다. 거대한 고목들은 검게 뒤틀렸고, 맑았던 시냇물은 독성 흑수로 가득 찼다. 그러나 여전히 한때 아름다웠던 흔적이 곳곳에 남아 있다.

흑수는 최소 15m 폭의 채널로 흘러 존 경계를 형성한다. 채널은 직선이 아닌 유기적 곡선 형태. 플레이어가 존을 선택하면 해당 구역의 흑수가 후퇴하며 지형이 드러난다.

### 고도 프로파일

```
     ║

+33m ║Z23/Z24
+29m ║Z21/Z22

+21m ║Z15/Z16/Z17
+17m ║Z12/Z13/Z14
+13m ║Z9/Z10/Z11
 +9m ║Z6/Z7/Z8
 +5m ║Z4/Z5
 +2m ║Z2/Z3
  0m ║Z1 (시작)
```

## 3. 26존 상세 설계

범례:
```
T = 대형 나무 (엄폐물)    t = 소형 나무    R = 바위/뿌리 (엄폐물)
W = 벽/잔해 (엄폐물)      ~ = 흑수/위험지대  P = 발판 (Platform)
▲ = 고지대 진입로         S = 적 스폰 포인트  C = 체크포인트
H = 히든 보상             X = 플레이어 진입점  · = 안전 지면
```

### Z1 — 숲의 입구 (Forest Entry)

| 항목 | 내용 |
|---|---|
| 레이어 | L1 (시작방) |
| 크기 | 30m × 30m |
| 고도 | +0m |
| 패턴 | 없음 (안전지대) |
| 컨셉 | 시작방 고정 |

**설명**: 부패하기 직전의 숲 가장자리. 한때 기사들이 순례를 시작하던 석조 신사 잔해. 멀린의 체크포인트 돌이 중앙에 놓여 있다.

```
T   T   T   T   T   T
  t   t   t   t   t
T   [shrine]   ·   T
  t    ·  C  ·    t
T   ·   ·   ·   ·   T
  t  →Z2     →Z3  t
T   T   T   T   T   T
```

**특이사항**: 전투 없음. Z2, Z3 방향 경로 명확히 보임. 멀린의 첫 대사 재생.

### Z2 — 수몰된 고목 지대 (Drowned Ancient Trees)

| 항목 | 내용 |
|---|---|
| 레이어 | L2 |
| 크기 | 45m × 45m |
| 고도 | +2m |
| 패턴 | RING (포위형) |
| 컨셉 | 전투방 |

**설명**: 흑수에 반쯤 잠긴 고목들이 기둥처럼 서 있는 지역. 노출된 거대한 뿌리들이 전투 구역 경계를 형성한다. 중앙 지반은 얕은 흑수로 덮여 이동 페널티.

```
  T         T         T
    [root1]   [root2]
  T    ·   ·   ·   ·  T
    [root3] ~~C~~ [root4]
  T    ·   ·   ·   ·  T
    [S]           [S]
  T         T         T
X(south)              X(south)
```

**전투 설계**: 적이 사방 가장자리에서 등장하여 중심부로 수렴. 중앙 흑수 지대는 이동 페널티(속도 -30%). 뿌리 4개 = 엄폐물.

### Z3 — 덩굴 수로 (Vine Waterway)

| 항목 | 내용 |
|---|---|
| 레이어 | L2 |
| 크기 | 35m × 50m |
| 고도 | +3m |
| 패턴 | PINCER (협공형) |
| 컨셉 | 전투방 |

**설명**: 덩굴로 뒤덮인 좁은 수로. 양쪽 덩굴 벽이 이동 경로를 제한한다. 적은 수로의 양 끝에서 동시에 진입.

```
VVVVVV VVVVVV VVVVVV
V  R  V  ·  V  R  V
V  ·  V  ·  V  ·  V   ← 수로 축 (남북)
V  R  V  ·  V  R  V
VVVVVV VVVVVV VVVVVV
S(north)       S(south)
   X              X
```

**전투 설계**: 적이 북쪽/남쪽에서 동시 진입(협공). 덩굴 벽이 측면 이동 제한. 바위 4개 = 엄폐물.

### Z4 — 안개 숲 갈림길 (Misty Forest Fork)

| 항목 | 내용 |
|---|---|
| 레이어 | L3 |
| 크기 | 55m × 40m |
| 고도 | +5m |
| 패턴 | CORRIDOR (선형형) |
| 컨셉 | 전투방 |

**설명**: 거대한 쓰러진 고목이 지역을 양분한다. 두 갈래 통로 중 하나로 진입, 나머지 통로에서 기습.

```
T T T T T T T T T T T
X→ [path A]→  →[path B] →X
   R  R  [fallen oak]  R
X→ [path A]→  →[path B] →X
T T T T T T T T T T T
S(west)        S(east)
```

**전투 설계**: 적이 진입 반대편 통로에서 선형 압박. 쓰러진 참나무 = 주요 엄폐물 + 구분선. 5개 엄폐물.

### Z5 — 이끼 암반 고원 (Mossy Rock Plateau)

| 항목 | 내용 |
|---|---|
| 레이어 | L3 |
| 크기 | 45m × 45m |
| 고도 | +6m (하단 기준, 상단 +9m) |
| 패턴 | TIERED (고저형) |
| 컨셉 | 전투방 |

**설명**: 이끼 낀 암반이 3m 높이 차이를 만드는 고원. 아래층은 근접전, 위층에서 원거리 적이 사격.

```
[low area +6m]  ▲  [ledge face]  ▲  [high area +9m]
   R   ·   R   /  /  /  /  /   ▲    R   ·   R
   ·   ·   ·  /climbing path/   ·   ·   ·
S(melee)     / / / / / / /   S(archers, high ground)
```

**전투 설계**: 고지대 적이 원거리 공격. 플레이어는 고지 점령 또는 저지대에서 엄폐 전투 선택. 5개 엄폐물.

### Z6 — 침식된 강변 섬 (Eroded Riverbank Islands)

| 항목 | 내용 |
|---|---|
| 레이어 | L4 |
| 크기 | 50m × 55m |
| 고도 | +8m |
| 패턴 | ISLAND (도서형) |
| 컨셉 | 전투방 |

**설명**: 흑수 개울 위에 솟은 3개의 석재 발판. 발판 사이는 좁은 돌다리로 연결. 떨어지면 흑수 피해.

```
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
~~~  [Platform A]  ~~ [Platform B] ~~  [Platform C]  ~~~
~~~   R  ·  R    ~~~~  R  ·  R   ~~~~ R  ·  R    ~~~
~~~~~~~ [bridge] ~~~~~~~~ [bridge] ~~~~~~~~~~~~~~~~~~~~~~~
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
S         S              S
```

**전투 설계**: 적이 각 발판에 등장. 발판 이동 시 넓은 흑수 도하(=피해). 낙하 = 흑수 피해 + 강제 복귀. 6개 엄폐물.

### Z7 — 천년 고목 뿌리 (Ancient Oak Root Arena)

| 항목 | 내용 |
|---|---|
| 레이어 | L4 |
| 크기 | 55m × 55m |
| 고도 | +9m |
| 패턴 | RING (포위형) |
| 컨셉 | 전투방 |

**설명**: 거대한 부패 참나무 아래의 원형 전투 구역. 지면 위로 솟은 뿌리 5개가 반원형 배치를 이루며 자연 장벽 형성.

```
       T   T   T   T   T
      T [root1] · [root2] T
     T  ·  ·  ·  ·  ·   T
    T [root3]  · [root4] T
     T   ·   C   ·   T
      T [root5]   ·  T
       T   T   T   T
         S   S   S
```

**전투 설계**: 중앙 원형 공간에 적이 사방에서 등장(RING). 뿌리 5개가 순환 전투 흐름 유도.

### Z8 — 부패한 사냥터 (Corrupted Hunting Ground)

| 항목 | 내용 |
|---|---|
| 레이어 | L4 |
| 크기 | 55m × 60m |
| 고도 | +8m |
| 패턴 | PINCER (협공형) |
| 컨셉 | 전투방 |

**설명**: 기사들이 사냥하던 평원. 지금은 부패한 짐승들의 영역. 산발적인 바위들이 광활한 공간을 분절.

```
T  T  T  T  T  T  T  T  T
  [B]   ·   [B]   ·   [B]
T  ·   ·   ·   ·   ·   ·  T
S←←← (flank)  C  (flank)→→→S
T  ·   ·   ·   ·   ·   ·  T
  [B]   ·   [B]   ·   [B]
T  T  T  T  T  T  T  T  T
```

**전투 설계**: 적이 동서 양 측면에서 동시 진입(협공). 열린 공간이 많아 운동성이 핵심. 바위 4~5개.

### Z9 — 이중 석판 아치 (Twin Stone Arches)

| 항목 | 내용 |
|---|---|
| 레이어 | L5 |
| 크기 | 40m × 60m |
| 고도 | +12m |
| 패턴 | CORRIDOR (선형형) |
| 컨셉 | 전투방 |

**설명**: 고대의 석판 아치 2개가 병렬 통로를 형성. 아치 사이는 단단한 돌벽. 좁은 병목 구간 전투.

```
[W]  [W]  [W arch pillar]  [W]  [W]
→  [arch A corridor]  →  [arch B corridor]  →
X    R      ·      R    ||   R     ·    R    X
→  [arch A corridor]  →  [arch B corridor]  →
[W]  [W]  [W arch pillar]  [W]  [W]
     S(north)              S(north)
```

**전투 설계**: 두 병렬 통로 사이를 이동하며 전투. 병목으로 인해 적의 수가 제한됨. 아치 기둥 4개 + 잔해 2개 = 6개 엄폐물.

### Z10 — 숨겨진 연못 광장 (Hidden Pond Plaza)

| 항목 | 내용 |
|---|---|
| 레이어 | L5 |
| 크기 | 60m × 60m |
| 고도 | +13m |
| 패턴 | RING + PINCER |
| 컨셉 | 전투방 (히든 보상 있음) |

**설명**: 깊은 숲 속에 숨겨진 부패한 연못 광장. 연못이 중앙을 차지하며, 가장자리 석판 표식이 전투 경계를 형성.

```
  T   T  [marker]  T   T
  T  [m]  ~~~~~  [m]  T
  t   ~~~ (pond) ~~~   t
  T  [m]  ~~~~~  [m]  T
    [H?] [marker] (stone slab)
S(N)          S(E)
         S(W)
```

**히든 보상**: 서쪽 무너진 석판 아래 (전투 중 돌아서 확인 필요).
**전투 설계**: 포위 + 협공 복합. 연못은 진입 불가 장애물. 석판 표식 5개 = 엄폐물.

### Z12 — 울부짖는 협곡 (Howling Gorge)

| 항목 | 내용 |
|---|---|
| 레이어 | L6 |
| 크기 | 45m × 65m |
| 고도 | +16m |
| 패턴 | CORRIDOR + ISLAND |
| 컨셉 | 전투방 |

**설명**: 양쪽 흑수가 급류로 흐르는 좁은 협곡. 징검다리 석판들이 통로를 형성. "울부짖음"은 흑수가 협곡을 통과하는 소리.

```
~~~~~~~~[P1]~~~~~~~~[P2]~~~~~~~~[P3]~~~~~~~~[P4]~~~~~~~~
~~  ~~  ·  (bridge)  ·  (bridge)  ·  (bridge)  ·  ~~  ~~
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
X(south)                                          X(north)
```

**전투 설계**: 발판 간 이동 중 공격. 협곡 바람(이펙트)으로 낙하 위험 암시. 4개 석판 발판. 가장자리 낙사 = 흑수 피해.

### Z13 — 거미 둥지 (Spider's Nest)

## 5. 지형 특수 요소

### 파수꾼 나무 (Sentinel Trees)

- 위치: Z15, 챕터 1 전역 특징
- 직경 5~10m의 거대 고목. 부패했지만 쓰러지지 않음.
- 역할: 엄폐물 + 지형 표식 + 분위기

### 부패한 폭포 (Corrupted Waterfall)

- 위치: Z14, Z17, 소규모 Z12
- 흑수가 폭포로 흐름. 접촉 = 경미한 DoT(초당 HP -2%) 또는 즉사(Z17).
- 역할: 환경 위험 + 히든 보상 단서

### 부패 간헐천 (Corruption Geyser)

- 위치: Z21
- 10초 간격으로 랜덤 위치에서 분출. 분출 전 지면 이펙트로 예고.
- 역할: 동적 환경 위험

### 수중 통로 (Underwater Passages)

- 위치: Z24
- 흑수 안을 통과하는 짧은 수중 구간. 통과 시 지속 피해.
- 역할: 히든 보상 접근

### 그린 나이트의 흔적

- 위치: Z7 (고목 뿌리의 새겨진 문양), Z24 (제단 석비)
- 서사 단편: 그린 나이트가 원래 기사들의 용기를 시험하던 수호자였음을 암시.

#### 페이즈 1 (HP 100% → 50%)

**가용 구역**: 전체 직경 80m

```

T  T  T  T  T  T  T  T  T  T  T
```

- 엄폐물: 고목 6개 (원형 배치)
- 그린 나이트 공격 패턴:
  - 근접 강타 (3연격)
  - 가시 투척 (3방향 팬)

#### 페이즈 2 (HP 50% → 25%, 전환 연출)

**전환 연출**: 그린 나이트가 HP 50% 도달 시 재생 시작 (초당 HP 0.5% 회복). 아레나 가장자리에서 흑수가 빠르게 침식. 나무 4그루가 흑수에 잠김.

**가용 구역**: 직경 55m (외곽 12m 흑수로 침식)

```
~~~~ T  T  T  T  T  T  T ~~~~
~~~~ ·  ·  ·  ·  ·  ·  · ~~~~
~~~~ ·  T  ·  (GK)·  T  · ~~~~
~~~~ ·  ·  ·  ·  ·  ·  · ~~~~
~~~~ T  T  T  T  T  T  T ~~~~
```

- 엄폐물: 고목 4개 (남은 나무)
- 추가 패턴:
  - 재생 중단 조건: 화염/불 피해
  - 지면 전체 덩굴 함정 (특정 경고 지역)
  - 고목에서 넝쿨 투사 (엄폐물이 적으로 활용됨)
- 환경: 흑수 가장자리 = 진입 시 지속 피해 (초당 HP -5%)

#### 페이즈 3 (HP 25% → 0%, 최종)

**전환 연출**: HP 25% 도달 시 그린 나이트 폭주. "재생" 포기, 공격 패턴 전면 변화. 흑수가 다시 빠르게 침식.

**가용 구역**: 직경 35m (외곽 22m 흑수로 침식)

```
~~~~~~~~~~~~~~~~~~~~~~~~~~~
~~~~~ ·  ·  ·  ·  · ~~~~~
~~~~~ ·  (GK)  · ~~~~~
~~~~~ ·  ·  X  · ~~~~~
~~~~~ ·  ·  ·  ·  · ~~~~~
~~~~~~~~~~~~~~~~~~~~~~~~~~~
```

- 엄폐물: 고목 2개 (마지막 남은 나무)
- 최종 패턴:
  - 폭주 강타 (피해 +50%, 범위 +30%)
  - 광역 가시 폭발 (전방향)
  - 분신 1개 생성 (HP 30%)
  - 재생 없음
- 환경: 아레나가 매우 좁아짐. 흑수 가장자리 = 즉사.
