# 2. 세계관 & 시나리오

## 2.1 배경 설정

아서왕 전설의 세계. 최고의 마법사 **멀린**이 의문의 외부 존재에 의해 살해된다.
그의 죽음과 동시에 세계는 부패하기 시작하고, 자연 · 고대 존재 · 인간 영웅들이 차례로 잠식된다.

멀린의 잔존 의지는 사후에도 흩어지지 않고 하나의 목적으로 수렴한다.
**"근원을 찾아라. 세상을 정상화하라."**

그는 세계 너머에서 **신성한 영혼**을 소환하고, 쓰러진 영웅들의 유물(육체)을 그 그릇으로 삼는다.
주인공은 영혼이다. 형체는 없다. 하지만 유물을 빌리면 싸울 수 있다.

> **모던 다크 동화 톤**
> 밝고 귀여운 동화가 아니다. 한때 빛났던 이야기가 부패하고 잠식된 세계.
> 잔해만 남은 동화책의 마지막 페이지 같은 분위기.

## 2.2 핵심 인물

### 멀린 (Merlin)
- 세계 최고의 마법사, 아서왕의 스승
- 게임 시작 시점에는 이미 사망
- **잔존 의지**로만 존재하며 주인공을 안내
- 런마다 돌아오는 허브 공간에서 목소리로 대화
- 진행하면서 점점 약해지다가 마지막에 진실을 고백

### 주인공 (신성한 영혼)
- 이름·형체 없음. 플레이어가 곧 영혼
- 멀린의 소환으로 세계에 존재
- 영웅의 유물(육체)을 빌려 전투
- 사망 시 멀린의 의지가 복구 → 재도전

### 모드레드 (Mordred) — 챕터 3 보스
- 원탁의 기사였으나 타락한 배신자
- 아서왕 전설에서도 아서를 배신한 인물
- 리치에게 잠식되기 전부터 어둠을 품었던 존재
- 영웅들 중 가장 먼저 리치의 도구가 된 자

### 리치 (The Lich) — 최종 보스
- 멀린의 육체를 탈취한 외부 존재
- 멀린의 전성기 마법 능력을 그대로 복사
- 세계 부패의 실질적 근원
- 쓰러지기 전 모르가나의 존재를 암시

### 모르가나 (Morgan le Fay) — 포스트 엔딩 암시
- 멀린의 제자이자 숙적
- 리치를 통해 멀린의 육체를 도구로 활용한 진짜 배후
- 리치 격파 후 목소리로만 등장 — 다음 챕터 암시

## 2.3 서사 아크 — 챕터별 빌드업

### 챕터 1 — 부패의 숲

**테마**: 혼돈, 원인 불명
**서사**: 세계가 이상하다는 것을 인지하는 단계. 멀린의 의지가 명확하게 주인공을 안내한다.

> *멀린의 의지: "영혼이여, 내가 힘을 불어넣어 주겠다. 근원을 찾아라."*

- 숲의 자연 수호자들이 부패
- 그린 나이트가 숲을 지배
- 영웅 유물 첫 발견 — "이 영웅은 왜 쓰러졌는가?"

**챕터 보스**: 그린 나이트 (The Green Knight)
- *가웨인과 녹색 기사* 전설의 인물
- 숲의 수호자가 부패로 거대화된 형태
- 가웨인 암시 유물을 사용하는 플레이어에게 특별 대사 출력

---

### 챕터 2 — 용암 대지

**테마**: 규모 확대, 부패의 깊이
**서사**: 고대 존재까지 잠식됐음을 확인. 멀린의 의지가 불안해지기 시작한다.

> *멀린의 의지: "이 부패는... 의지를 가지고 있어. 단순한 확산이 아니야."*

- 고대 용이 부패의 에너지에 잠식
- 영웅의 유물에서 기억 파편 발견 — "우리는 싸우다 쓰러진 게 아니라 — 당했다"

**챕터 보스**: 이 드레이그 고흐 (Y Ddraig Goch)
- 멀린이 직접 예언한 웨일스의 붉은 용
- 멀린이 예언했던 존재가 부패의 도구가 된 아이러니
- 격파 후 멀린: *"내가 예언한 존재가... 이렇게 쓰이다니."*

---

### 챕터 3 — 잠식된 성채

**테마**: 공포, 배후의 실체화
**서사**: 인간 영웅이 잠식됐음을 처음 목격. 리치의 직접 개입 흔적 발견.

> *멀린의 의지: "내 기억이 흐릿해지고 있어. 뭔가가 나를 갉아먹는 것 같아..."*

- 성채 전체가 리치의 부패 에너지로 점령
- 영웅들의 힘이 복사되고 있다는 단서 발견
- 리치가 의도적으로 영웅들을 분석·복사해왔음 확정

**챕터 보스**: 모드레드 (Mordred)
- 원탁의 기사, 리치에게 잠식된 배신자
- 격파 후 잠시 의식을 되찾으며 단서 제공
- *"그 자는... 모든 것을 복사했어. 너희까지도..."*

---

### 챕터 4 — 암흑대지 (최종)

**테마**: 근원, 비극적 클라이맥스
**서사**: 모든 진실이 드러나고 주인공이 최대 위기에 직면한다.

```
입장
  → 역대 영웅 복사체 연속전 (플레이어가 써온 유물의 복사체 포함)
  → 멀린의 마지막 메시지 재생
  → 리치 (멀린의 육체) 최종 보스전
  → 엔딩 + 모르가나 암시
```

**최종 챕터 직전 멀린의 대사**:
> *"알아냈어. 내 육체가... 잠식됐어."*
> *"부탁해. 막아줘."*

**리치 격파 후 엔딩**:
> 리치가 쓰러지며 마지막으로 웃음
> *"...멍청한 영혼. 이건 시작에 불과했는데."*
>
> 어딘가에서 모르가나의 목소리:
> *"잘했어. 실험은 끝났으니까."*
>
> 멀린의 의지 (희미하게):
> *"모르가나... 역시 그녀였군. 아직... 끝나지 않았어."*

## 2.4 멀린의 의지 — 내러티브 엔진

멀린의 의지 상태가 런 진행에 따라 변화하며 게임의 서사 온도를 조율한다.

| 런 구간 | 멀린 상태 | 허브 분위기 | 대사 톤 |
|---|---|---|---|
| 1~10런 | 강하고 명확 | 탑 잔해, 희미한 빛 | 단호하고 목적적 |
| 10~30런 | 불안, 단편적 | 빛이 줄어듦 | 걱정, 혼란 |
| 30~50런 | 희미해짐 | 탑이 더 어두워짐 | 쉰 목소리, 끊김 |
| 최종 챕터 | 마지막 각성 | 한순간 밝아짐 | 간절하고 절박함 |

# 3. 코어 게임 루프

## 3.1 거시적 루프

```
[허브: 멀린의 탑 잔해]
        ↓ 영웅 유물 + 장비 선택
[런 시작]
        ↓ 방 탐색 + 전투
[챕터 1~4 진행]
        ↓ 사망 또는 클리어
[허브 복귀]
        ↓ 재화 소비 (서약/해방/각성)
[강해진 영혼으로 재도전]
```

## 3.2 미시적 루프 (인게임)

```
[런 시작]
    → 서약 3종 중 1개 선택 (기본 상태)
[방 입장]
    → 전투 수행
    → 아이템 획득 → 그리드 배치
    → 방 클리어 보상 (골드/아이템/봉인된 기억)
    → 다음 방 선택 (노드 맵)
[이벤트방]
    → 보유 서약 중 1개 선택 → 서약 강화 (수치 개선)
[특별 분기 구간]
    → 서약 추가 획득 (최대 3~4개까지)
[보스방]
    → 보스 처치 → 보유 서약 중 1개 선택 → 서약 진화 (기능 변환)
    → 유물 코어 획득 (첫 격파 시)
    → 다음 챕터 또는 엔딩
```

### 사망 & 다시하기 규칙

- **사망 화면**: HP 0 시 블랙 페이드 + 카메라 캐릭터 줌인 후 "다시하기 / 포기" 선택
- **다시하기 저장 시점**: 노드 맵에서 방을 **선택한 순간** 저장 (방 클리어 후가 아님)
- **재시작 지점**: 사망한 방이 아닌 **선택했던 방 입구**부터 재진입
  - 이미 클리어한 방의 보상은 유지되지 않음 (전투는 초기화)
  - 노드 그래프 상태(Cleared/Visited)는 저장 유지

## 3.3 씬 구성

| 씬 | 역할 |
|---|---|
| **로그인** | 계정 인증 |
| **로비** | 영웅 유물 선택, 장비 선택, 멀린의 서약 접근 |
| **스테이지맵** | 노드 기반 방 선택 |
| **게임씬** | 실제 전투 |
| **결과** | 런 결과, 재화 정산 |

# 4. 영웅 유물 시스템

## 4.1 시스템 개요

> "영웅의 이름은 잊혀졌다. 남은 건 유물뿐이다."

- 영웅 유물 = 쓰러진 영웅의 육체
- 정체는 **패시브 이름·스킬 이름·고유 대사**로만 암시
- 플레이어가 직접 유추하는 재미
- 모든 영웅이 모든 장비 사용 가능
- 영웅마다 **고유 패시브 + 고유 스킬 + 고유 메커닉** 보유

## 4.2 영웅별 상세 설계

---

### 유물 1 — [성배의 수호자] `기본 제공`

> 암시: 갈라하드 (Galahad) — 원탁에서 가장 성스러운 기사, 성배를 완성한 유일한 존재

**스타일**: 방어형 / 초보 친화 / 진입장벽 낮음

#### 기본 스탯
| 스탯 | 수치 |
|---|---|
| 기본 HP | 150 |
| 기본 공격력 | 80 |
| 기본 방어력 | 40 |
| 이동속도 | 표준 (1.0x) |

#### 고유 패시브
| 패시브명 | 효과 |
|---|---|
| **성스러운 방패** | 방어 입력 시 받은 피해의 30%를 전방 적에게 반사 |
| **아버지의 죄** | 피격 시 신성 게이지 +15 충전. 방어 성공 시 +25 충전 |

#### 고유 스킬: **성배의 빛**
- 쿨다운: 18초
- 효과: 전방 4m 범위 신성 폭발. 피해량 공격력 × 180%
- 신성 게이지 30 이상일 때 사용 시 범위 +50%, 피해량 +50%

#### 고유 메커닉: **신성 게이지**
```
최대 게이지: 100
충전:
  피격 시 +15
  방어 입력 성공 시 +25
  성배의 빛 사용 시 +20

만충(100) 달성 시:
  → 5초간 무적 + 공격력 150% + 신성 게이지 빛 연출
  → 이후 30초 쿨다운 (재충전 불가)
```

#### 메커닉 변형 아이템 예시
| 아이템명 | 효과 |
|---|---|
| *죄의 대가* | 공격 시에도 게이지 +8 충전 → 공격형 전환 |
| *성배의 축복* | 게이지 50마다 소폭 효과 발동 (무적 없이) → 지속형 |
| *순교의 서약* | 게이지 만충 효과 지속시간 5초 → 10초 |

---

### 유물 2 — [원탁의 균열] `봉인된 기억 3개`

# 5. 장비 & 빌드 시스템

## 5.1 장비 구조

모든 영웅이 모든 장비 사용 가능.
장비 = 액티브 스킬셋 + 기본 공격 방식 결정.

| 장비 유형 | 공격 스타일 | 특징 |
|---|---|---|
| **카타나** | 고속 연속기 | 짧은 사거리, 높은 공격 속도 |
| **대검** | 강타형 | 긴 사거리, 낮은 공격 속도, 높은 단타 피해 |
| **창** | 돌진/관통형 | 직선 관통, 중간 속도 |
| **활** | 원거리 | 긴 사거리, 투사체 |
| **검+방패** | 방어형 | 방어 기능 포함, 균형 스탯 |

## 5.2 아이템 이중 효과 구조

모든 아이템은 **범용 효과 + 영웅 친화 보너스** 두 줄 보유.

```
[분노의 맹세]
─────────────────────────
기본 효과:   공격력 +10%
─────────────────────────
원탁의 균열 친화:
  피격 시 콤보 게이지 +3 충전
─────────────────────────
```

- 범용 효과: 어떤 영웅이든 장착 가능
- 친화 보너스: 해당 영웅 장착 시만 발동
- 드롭 풀: 현재 영웅의 메커닉 기준 **가중치 조정** (친화 아이템 30% 상향)

## 5.3 영웅 × 장비 × 메커닉 조합표

| | 카타나 | 대검 | 창 | 활 | 검+방패 |
|---|---|---|---|---|---|
| **성배의 수호자** | 공격으로 게이지 충전 어려움 | 강타 후 피격 유도 → 탱딜 | 표준 | 원거리 게이지 지연 | 방어+게이지 최적 ★ |
| **원탁의 균열** | 콤보 빠른 충전 ★ | 리스크 고보상 | 돌진 콤보 | 안전 딜링 | 방어적 콤보 |
| **여정의 창** | 빠른 처치 → 스택 누적 | 보스킬러 빌드 ★ | 돌진+스택 시너지 ★ | 안전 누적 | 균형형 |
| **태양의 서약** | 강화 구간 연속딜 | 강화 구간 강타 ★ | 강화 구간 돌진 | 원거리 버스트 | 방어 유지 ★ |
| **비련의 화살** | 근접 → 거리 페널티 위험 | 근접 → 페널티 최고위험 | 히트앤런 | 거리 최적 ★ | 방어로 근접 방지 |

★ = 높은 시너지 조합

# 6. 런 내 성장 시스템

## 6.1 스탯 레이어 구조 (7단계 합산)

```
최종 스탯 =
  [1] 기본 (영웅 유물 기본 스탯)
+ [2] 서약 (멀린의 서약 영구 보너스)
+ [3] 유물 각성 (해금된 각성 효과)
+ [4] 장비 (선택한 장비 스탯)
+ [5] 아이템 (그리드 배치된 아이템 합산)
+ [6] 서약 (활성화된 서약 효과)
+ [7] 시너지 (그리드 시너지 Always/조건부)
```

## 6.2 아이템 시스템

### 아이템 획득 ~ 효과 적용 흐름
```
적 처치 또는 방 보상
  → 아이템 드롭 (등급별 확률)
  → Staging(임시 보관) — 효과 없음
  → 플레이어가 그리드에 배치
  → ItemEffectManager.Rebuild()
  → 효과 발동
```

### 아이템 등급 및 드롭 확률

| 등급 | 기본 확률 | 효과 특성 |
|---|---|---|
| Common | 55% | 범용 스탯 보정 |
| Rare | 30% | 조건부 효과 + 영웅 친화 보너스 |
| Epic | 12% | 메커닉 변형 |
| Legendary | 3% | 빌드 완전 전환 |

> 멀린의 서약 "아이템 등급 상승" 항목 보유 시 확률 조정
> 럭(Luck) 스탯이 높을수록 Rare 이상 확률 증가

### 아이템 효과 트리거 종류

| 트리거 | 발동 조건 |
|---|---|
| Always | 배치 즉시 영구 적용 |
| OnHit | 공격 적중 시 발동 |
| OnKill | 적 처치 시 발동 |
| OnRoomClear | 방 클리어 시 발동 |
| OnLowHp | HP 30% 이하 시 발동 |
| OnBossClear | 보스 처치 시 발동 |

## 6.3 그리드 시너지

아이템의 `shapeId`에 따라 퍼즐 보드에 블록 배치. 그리드 완성 시 시너지 발동.

### 시너지 트리거

| 트리거 | 조건 | 효과 방식 |
|---|---|---|
| **Always** | 그리드 완성 즉시 | 스탯 영구 반영 |
| **OnHit** | 공격 적중 시 스택 누적 | 최대 스택까지 누적, duration 초 유지 |
| **OnLowHp** | HP ≤ threshold | 조건 만족 시 활성화 |

### 그리드 완성 보상 예시

| 시너지명 | 트리거 | 효과 |
|---|---|---|
| *기사의 각오* | Always | 공격력 +15% |
| *원탁의 결속* | Always | MaxHP +50 |
| *심판의 일격* | OnHit | 스택당 공격력 +2% (최대 10스택) |
| *사지의 저항* | OnLowHp | 방어력 +40%, 이동속도 +15% |

## 6.4 서약 시스템

> *"멀린이 살아있던 시절, 그는 강력한 존재들과 계약을 맺었다.*
> *그 서약들은 지금도 봉인된 채로 남아있다.*
> *런마다 봉인이 하나씩 열린다."*

### 개요

서약 시스템은 런 내 성장의 핵심 레이어다. 각 서약은 멀린이 살아있던 시절 강력한 존재들과 맺은 고대 계약이며, 단순한 수치 강화가 아닌 플레이 방식 자체를 결정하는 아이덴티티 능력이다.

### 획득 구조

| 시점 | 내용 |
|---|---|
| **런 시작** | 3종 중 1개 선택 (기본 상태) |
| **이벤트 방 클리어** | 보유 서약 중 1개 선택 → 강화 (수치 개선) |
| **특별 분기 구간** | 서약 추가 획득 |
| **보스 처치** | 보유 서약 중 1개 선택 → 진화 (기능 변환) |

> 런당 최대 보유 서약: 3~4개

### 서약 3단계 성장

| 단계 | 트리거 | 내용 |
|---|---|---|

## 7.3 유물 해방 (봉인된 기억 소비)

> "기억이 쌓이면 잠들어 있던 영웅의 유물이 깨어난다."

| 유물 | 비용 | 누적 필요량 |
|---|---|---|
| 원탁의 균열 | 봉인된 기억 ×3 | ×3 |
| 여정의 창 | 봉인된 기억 ×5 | ×8 |
| 태양의 서약 | 봉인된 기억 ×8 | ×16 |
| 비련의 화살 | 봉인된 기억 ×12 | ×28 |

### 봉인된 기억 획득 방식

확률 드롭에 의존하지 않는다. 챕터 보스 처치에 보장 수량이 연결된다.

| 획득처 | 수량 | 조건 |
|---|---|---|
| 챕터1 보스 처치 | ×1 보장 | 봉인 상태 격파 포함 |
| 챕터2 보스 처치 | ×1 보장 | 봉인 상태 격파 포함 |
| 챕터3 보스 처치 | ×2 보장 | 봉인 상태 격파 포함 |
| 챕터4 보스 처치 | ×2 보장 | 봉인 상태 격파 포함 |
| 이벤트방 / 엘리트방 확률 드롭 | ×0~1 | 보너스 성격 |

> 풀클리어 1런 = 보장 6개 + 기대 드롭 1~2개 ≈ 7~8개/런
> 전체 해방(×28) 기준 약 4~5런의 풀클리어 또는 챕터별 부분 클리어 조합

### 사망 카운터 시스템

> "고통도 기억이다."

5회 사망 누적 시 봉인된 기억 ×1 보장 지급. 카운터 초기화.

```
사망 카운터: 0 ─ 1 ─ 2 ─ 3 ─ 4 ─ [5] → 봉인된 기억 +1
```

- 리치를 못 잡더라도 반복 시도 자체가 영웅 해방에 기여
- 멀린 대사: *"고통도 기억이다. 받아라."*

## 7.4 유물 각성 (유물 코어 소비)

> "유물이 진짜 이름과 힘을 되찾는다. 영웅의 진정한 각성."

각 영웅 유물마다 Tier 1~3 각성 존재. 각성할수록 고유 메커닉이 심화된다.

### 각성 비용

| 각성 Tier | 필요 유물 코어 | 영웅 1개 누적 | 효과 방향 |
|---|---|---|---|
| Tier 1 | ×1 | ×1 | 메커닉 수치 강화 |
| Tier 2 | ×3 | ×4 | 메커닉에 새로운 조건 추가 |
| Tier 3 | ×6 | ×10 | 메커닉 근본 확장 |

> 영웅 5개 전체 완전 각성 기준 총 코어 ×50 필요.

### 코어 획득 경로

| 경로 | 수량 | 조건 |
|---|---|---|
| 완전 해방 보스 첫 격파 | ×1 | 3차+ 조우에서 처음 완전 격파 시 (보스당 1회) |
| 리치 첫 격파 | ×1 | 부패 변이 수식어 해금과 함께 지급 |
| 잔류 각인 교환 | ×1 / 각인 ×5 | 반복 획득 경로 (허브에서 교환) |

> 초기 코어 확보 경로: 챕터 1~3 보스를 각각 3차+ 조우에서 격파 → 코어 ×3 → 원하는 영웅 Tier 1 각성 즉시 가능.
> 장기 목표: 잔류 각인을 통해 나머지 코어 수집 (변이 보스 반복 격파).

### 성배의 수호자 각성 예시

| 각성 | 효과 |
|---|---|
| Tier 1 | 신성 게이지 만충 효과 지속 5초 → 8초 |
| Tier 2 | 신성 게이지 50% 이상 시에도 소폭 효과 발동 (무적 없이, 공격력 +30%) |
| Tier 3 | 신성 게이지 만충 후 쿨다운 중에도 피격 시 게이지 소량 재충전 가능 |

## 7.5 보스 봉인 시스템

> "리치가 씌운 봉인. 영혼이 닿을 때마다 균열이 생긴다. 균열이 충분히 쌓이면 봉인은 스스로 파열된다."

### 구조 개요

보스는 리치의 봉인에 억압된 채 전투에 임한다. 플레이어가 같은 보스를 반복해서 격파할수록 봉인에 균열이 누적되고, **3차 조우부터 봉인이 스스로 파열되어 완전 해방 상태**로 전환된다. 리치 격파 여부와 무관하게 다회차 도전 자체가 해방의 열쇠다.

| 단계 | 조건 | 보스 상태 | Phase | 보상 |
|---|---|---|---|---|
| **봉인 상태** | 1차 조우 | HP 0 → 균열 연출 후 퇴각 | Phase 1만 | 봉인된 기억 보장 + 잔재 |
| **봉인 균열 예고** | 2차 조우 | Phase 2 형태를 10~20초 노출 후 다시 봉인 | Phase 1 + Phase 2 예고 | 봉인된 기억 보장 + 잔재 |
| **완전 해방** | 3차+ 조우 | 봉인 파열. Phase 2 완전 해금 | Phase 1 + Phase 2 | **유물 코어 ×1 (첫 완전 격파 시)** |
| **부패 변이** | 리치 격파 이후 재도전 | 랜덤 변이 수식어 1개 추가 | Phase 1 + 2 + 변이 | 잔류 각인 ×3~5 |

### Phase 2 설계 원칙

> **Phase 2는 수치 단순 강화가 아닌 패턴 셋 교체다.**

봉인 해방 시 HP는 같거나 소폭 증가하는 수준이며, 핵심 변화는 **완전히 다른 공격 패턴 세트**가 등장하는 것이다. 이를 통해 플레이어가 이미 학습한 보스가 새로운 경험으로 다가오며, '챕터 N 해방 보스 > 챕터 N+1 봉인 보스' 의 수치 역전 문제를 방지한다.

- Phase 1 패턴: 기본 패턴 셋 (학습 곡선용)
- Phase 2 패턴: 완전히 교체된 패턴 셋 (다른 전략 요구)
- HP 증가: 봉인 기준 +10~15% 수준 (챕터 간 밸런스 유지)

### 봉인 균열 예고 — 조우 횟수별 Phase 2 노출 시간

| 조우 횟수 | Phase 2 노출 시간 | 연출 |
|---|---|---|
| 1차 | 없음 | HP 0 → 봉인 파열 → 퇴각 |
| 2차 | 10~20초 | Phase 2 형태로 전환 후 공격 몇 회 → 다시 봉인 |
| 3차+ | 완전 해방 | 봉인 파열. Phase 2 영구 해금 |

멀린 대사 (균열 심화):
- 2차: *"봉인에 균열이 생겼어. 네 영혼이 닿았다."*
- 3차+: *"균열이 완전히 벌어졌어. 봉인이... 스스로 깨지고 있다."*

### 리치 격파 — 부패 변이 해금

리치 격파는 보스 봉인 해제와 무관하다. 대신 **부패 변이 수식어 풀**을 해금하는 마일스톤이다.

```
리치 사망
  ↓
유물 코어 ×1 지급 (리치 자체 격파 보상)
  ↓
멀린: "리치가 쓰러졌다. 하지만... 이건 끝이 아니야."
      "부패가 남긴 흔적들이 변이를 일으키고 있어."
  ↓
이후 런부터 완전 해방 상태 보스에 부패 변이 수식어 1개 랜덤 추가
```

### 부패 변이 수식어 풀

리치 격파 이후, 완전 해방 보스 재도전 시 랜덤 수식어 1개 부여:

| 분류 | 수식어명 | 효과 |
|---|---|---|
| 공격 | 분노의 부패 | 공격력 +40%, 공격 속도 +20% |
| 공격 | 관통의 저주 | 모든 공격 방어 무시 |
| 공격 | 연쇄의 광기 | 피격 시 주변에 연쇄 피해 |
| 방어 | 철갑의 잠식 | 받는 피해 -40%, HP 회복 불가 |
| 방어 | 재생의 부패 | 초당 최대HP 0.3% 회복 |
| 환경 | 독안개 확산 | 전장 외곽에서 독 안개 서서히 수축 |
| 환경 | 중력 왜곡 | 플레이어 대시/점프 거리 -30% |
| 특수 | 기억 역류 | 이번 런 첫 획득 아이템 효과를 보스가 사용 |

## 7.6 성장 시간대 설계

| 구간 | 주요 목표 | 재화 소비처 | 멀린 상태 |
|---|---|---|---|
| **1~5런** | 서약 생존 슬롯 안정화, 챕터2 첫 도달 | 영혼의 잔재 집중 | 명확하고 강함 |
| **5~15런** | 유물 해방 1~2개, 서약 공격/이동 해금 | 봉인된 기억 + 잔재 | 흐릿해지기 시작 |
| **15~30런** | 리치 첫 격파 도전, 서약 3~4번 슬롯 투자 | 잔재 + 기억 | 희미해짐 |
| **15~30런** | 완전 해방 보스 도전 (3차+ 조우 달성), 코어 획득 시작 | 코어 투자 시작 | 희미해짐 |
| **리치 첫 격파** | 부패 변이 해금 + 코어 ×1, 서약 5~6번 해금 | 잔류 각인 → 코어 | 마지막 각성 |
| **리치 이후** | 변이 챌린지, 나머지 각성 진행 | 잔류 각인 → 코어 | 서사 완결 |

# 8. 챕터 & 레벨 디자인

## 8.1 챕터 개요

| 챕터 | 배경 | 보스 | 몬스터 배수 | 보상 배수 |
|---|---|---|---|---|
| 1 | 부패의 숲 | 그린 나이트 | ×1.0 | ×1.0 |
| 2 | 용암 대지 | 이 드레이그 고흐 | ×1.5 | ×1.4 |
| 3 | 잠식된 성채 | 모드레드 | ×2.2 | ×1.8 |
| 4 | 암흑대지 | 리치 (멀린의 육체) | ×3.0 | ×2.5 |

## 8.2 단일 세계 맵 시스템

### 핵심 컨셉

> **"맵 전체가 처음부터 존재한다. 다만, 길이 막혀 있을 뿐이다."**
>
> 챕터 = 하나의 거대한 물리 세계.
> 부패의 물질(흑수·용암·안개·공허)이 세계를 뒤덮고 있으며,
> 존을 클리어·선택하면 그 구역의 장벽이 물러난다.
> 플레이어는 드러나는 경로를 따라 보스 구역을 향해 직접 걸어 나아간다.

**기존 타일 맵 방식과의 차이**

| 항목 | 구 방식 (타일 맵) | 신 방식 (단일 세계) |
|---|---|---|
| 세계 존재 방식 | 방 선택 시 맵 인스턴스 생성 | 전체 맵이 처음부터 물리적으로 존재 |
| 이동 방식 | 타일 클릭 → 씬 로드 | 플레이어가 직접 지형을 걸어서 이동 |
| 장벽 처리 | UI 상 봉인 표시 | 장벽 물질이 실제 지형을 덮고 있음 |
| 탐험감 | 없음 (추상적 노드) | 있음 (발견·탐험 감각) |

---

### 26-존 레이어 구조

각 챕터는 **26개의 존(Zone)** 으로 구성된다.
플레이어는 런마다 레이어당 1개씩, **총 12개의 존**을 방문한다.

```
L12:                      [Z26]          ← 보스방 (고정)
L11:                   [Z25]
L10:              [Z23]    [Z24]
 L9:         [Z21]    [Z22]
 L8:    [Z18]    [Z19]    [Z20]
 L7:    [Z15]    [Z16]    [Z17]
 L6:    [Z12]    [Z13]    [Z14]
 L5:    [ Z9]    [Z10]    [Z11]
 L4:    [ Z6]    [ Z7]    [ Z8]
 L3:         [ Z4]    [ Z5]
 L2:         [ Z2]    [ Z3]
 L1:              [Z1]               ← 시작방 (고정)
```

| 레이어 | 존 번호 | 존 수 | 비고 |
|---|---|---|---|
| L1 (시작) | Z1 | 1 | 고정, 전투 없음 |
| L2 | Z2~Z3 | 2 | |
| L3 | Z4~Z5 | 2 | |
| L4 | Z6~Z8 | 3 | |
| L5 | Z9~Z11 | 3 | |
| L6 | Z12~Z14 | 3 | |
| L7 | Z15~Z17 | 3 | |
| L8 | Z18~Z20 | 3 | |
| L9 | Z21~Z22 | 2 | |
| L10 | Z23~Z24 | 2 | |
| L11 | Z25 | 1 | 보스 전 준비존 |
| L12 (보스) | Z26 | 1 | 고정, 보스전 |

**합계: 26존 / 런당 방문: 12존 (레이어당 1개 선택)**

---

### 존 연결 구조 (슬라이딩 윈도우)

각 존은 다음 레이어의 인접 2~3개 존과 연결된다.
가장자리 존: 2개 연결 / 중앙 존: 3개 연결.

```
Z1  → Z2, Z3
Z2  → Z4, Z5        Z3  → Z4, Z5
Z4  → Z6, Z7        Z5  → Z7, Z8
Z6  → Z9, Z10       Z7  → Z9, Z10, Z11   Z8  → Z10, Z11
Z9  → Z12, Z13      Z10 → Z12, Z13, Z14  Z11 → Z13, Z14
Z12 → Z15, Z16      Z13 → Z15, Z16, Z17  Z14 → Z16, Z17
Z15 → Z18, Z19      Z16 → Z18, Z19, Z20  Z17 → Z19, Z20
Z18 → Z21, Z22      Z19 → Z21, Z22       Z20 → Z21, Z22
Z21 → Z23, Z24      Z22 → Z23, Z24
Z23 → Z25           Z24 → Z25
Z25 → Z26
```

존을 클리어하면 연결된 다음 레이어 존들이 공개되고, 플레이어는 그중 하나를 선택한다.

---

### 존 상태 정의

| 상태 | 설명 | 시각적 표현 |
|---|---|---|
| **Sealed** | 장벽 물질로 봉인됨 | 장벽이 지형을 덮음, 지형 실루엣만 보임 |
| **Available** | 인접 존 클리어로 선택 가능 | 장벽 일부 후퇴, 존 컨셉 아이콘 표시 |
| **Selected** | 플레이어 선택, 개방 연출 중 | 장벽 완전 후퇴 애니메이션 재생 |
| **Active** | 현재 플레이 중 | 존 구역 하이라이트 |
| **Cleared** | 클리어 완료 | 체크포인트 활성화, 이동 가능 |

---

### 존 컨셉 분포 (26존 기준, 런당 12존 방문)

| 컨셉 | 전체 수량 | 런당 방문 | 내용 |
|---|---|---|---|
| **시작방** | 1 (고정) | 1 | 준비 공간, 전투 없음 |
| **전투방** | 14 | ~6 | 일반 전투, 아이템 보상 |
| **엘리트방** | 5 | ~2 | 강화 몬스터, 높은 보상 |
| **상점방** | 3 | ~1 | 인게임 골드로 아이템 구매 |
| **이벤트방** | 2 | ~1 | 선택지, 서사 단편, 특수 보상 |
| **보스방** | 1 (고정) | 1 | 챕터 보스 |

> 런마다 레이어별 선택에 따라 방문 컨셉 구성이 달라짐.
> 챕터 4는 보스방 이전 이벤트방 1개가 **영웅 복사체 방**으로 대체됨.

---

### 존 선택 흐름

```
[존 클리어]
  ↓
클리어된 존 → Cleared 상태 / 체크포인트 활성화
연결된 다음 레이어 존들 → Available 공개
  ↓
플레이어: 공개된 존 정보 확인
  (컨셉 아이콘 / 예상 보상 타입 / 히든 보상 존재 힌트)
  ↓
플레이어: 존 선택
  ↓
[멀린 상호작용 연출]
  - 장벽 후퇴 파문 이펙트
  - 플랫폼(연결 지형) 장벽 위로 상승
  - 체크포인트 활성화
  ↓
플레이어: 직접 걸어서 다음 존으로 이동
```

---

### 챕터별 장벽 테마

| 챕터 | 배경 | 장벽 | 시각 표현 |
|---|---|---|---|
| 1 | 부패의 숲 | **흑수 (Water)** | 범람한 검은 물, 부패한 강이 길을 막음 |
| 2 | 용암 대지 | **용암 (Lava)** | 흐르는 용암류, 화산재 장벽 |
| 3 | 잠식된 성채 | **안개 (Fog)** | 마법 안개, 시야 차단형 |
| 4 | 암흑대지 | **공허 (Void)** | 공허의 균열, 허공에 갈라진 틈 |

---

### 부패 압박 시스템 (Corruption Pressure)

클리어하지 않고 지나친 존은 챕터 보스를 강화한다.

| 미클리어 존 수 | 보스 강화 |
|---|---|
| 0 | 기본 상태 |
| 1~3 | 보스 HP +5% / 존 |
| 4~7 | HP +5% / 존 + 패턴 1개 추가 |
| 8+ | HP +5% / 존 + 패턴 2개 추가 + 필드 부패 이펙트 |

> 최단 경로만 달리면 보스가 강해지는 구조. 탐험 FOMO를 자연스럽게 유도한다.

---

### 히든 보상 시스템

일부 존에는 지형 내 **히든 보상**이 숨겨져 있다.
전투 중 발견 가능한 숨겨진 장소(잔해 뒤, 고목 위, 절벽 아래 등).

| 항목 | 내용 |
|---|---|
| 히든 보상 존 비율 | 26존 중 약 8존 |
| 보상 타입 | 재화 캐시 / 소형 아이템 / 서사 단편 |
| 발견 조건 | 전투 중 지형 탐색 (별도 상호작용 불필요) |

---

### 단축로 시스템 (Shortcut)

특정 조건의 인접 존 두 곳이 모두 클리어될 때 **단축 경로**가 개방된다.

- 단축로: 이미 클리어한 존 사이를 직접 연결하는 지형 통로
- 용도: 상점 재방문, 탐색, 체크포인트 복귀
- 조건: 단축로 양 끝 존이 모두 Cleared 상태

---

### 멀린 상호작용 서사 설계

| 챕터 | 멀린 상태 | 연출 방향 |
|---|---|---|
| 1 | 명확하고 단호 | 힘찬 음성, 장벽 빠르게 후퇴 |
| 2 | 약간의 불안 | 약간 떨리는 음성, 후퇴 속도 -10% |
| 3 | 단편적, 끊김 | 음성 잡음 섞임, 장벽 후퇴 멈칫거림 |
| 4 | 마지막 각성 | 가장 약하지만 의지적 — *"막아줘"* |

## 8.3 보스 상세 설계

### 그린 나이트 (챕터 1)

**설정**: 숲의 수호자가 부패로 거대화된 형태. 원래는 기사들을 시험하는 존재였으나 부패에 잠식됨.

#### Phase 1 — 봉인 상태 (1차·2차 조우)

| 항목 | 내용 |
|---|---|
| HP | 기본 HP × 1.0 (챕터 1 기준) |
| 1차 HP 0 연출 | 봉인 파열 → 퇴각. 멀린: *"봉인에 균열이 생겼어."* |
| 2차 HP 0 연출 | 균열 심화 연출 → Phase 2 형태 10~20초 노출 후 재봉인 |
| 처치 보상 | 영혼의 잔재 ×250, 봉인된 기억 ×1 보장 |

#### Phase 2 — 완전 해방 (3차+ 조우, HP 50% 이하 전환)

| 항목 | 내용 |
|---|---|
| 발동 조건 | HP 50% 이하 진입 시 (3차+ 조우부터 영구 해금) |

### 방 구조 설계 원칙

#### 바인딩 포인트 (Binding Points)

- 방은 단순 직사각형뿐 아니라 **비어있는 오브젝트 앵커(바인딩 포인트)**를 사용해 다양한 구조를 제작한다.
- MAP_TOKEN 그리드 외에 추가 앵커(`B<id>`)를 정의하여 특수 장식물·장애물·연출 오브젝트를 배치한다.
- 바인딩 포인트 활용 예: 부러진 기둥, 대형 나무, 제단, 지형 구멍 등
- 방마다 최소 2개의 바인딩 포인트를 포함하여 시각 다양성을 확보한다.

#### 벽 높이 & 카메라 차단

- 방 외곽 벽의 높이는 **카메라 FOV 기준 플레이어 시야를 가리는 높이** 이상으로 설정한다.
- 탑다운 쿼터뷰 특성상 벽이 짧으면 방 외부가 보여 몰입감이 깨짐 → 최소 벽 높이 기준 강제.
- 카메라 오클루전 처리: 카메라와 플레이어 사이 벽이 있으면 알파 페이드 처리 (Cinemachine 오클루전).

# 10. 전투 연출 & 게임 느낌

## 10.1 마지막 몬스터 슬로우모션 & 카메라 타게팅

전투 방에서 생존 몬스터가 **1마리**가 되는 순간:

- `Time.timeScale` → 0.3배 감속 (슬로우모션)
- Cinemachine 카메라 LookAt → 마지막 몬스터 추적
- 마지막 몬스터 처치 시 `timeScale` 1.0으로 복원
- **발동 범위**: 웨이브 모드 (`RoomWaveController` waveMode) / 레거시 모드 모두 적용

> 보스방은 별도 연출 처리 (보스 슬로우모션 별도 제작).

## 10.2 아이템 획득 연출

아이템 획득 시 순서:

1. 월드 스페이스 팝업 — 아이템명 + 등급 색상 (Common=흰, Rare=파랑, Epic=보라, Legendary=금)
2. 파티클 버스트 이펙트 (등급별 색상 파티클)
3. (Epic 이상) 짧은 카메라 줌인 0.5초

## 10.3 공격 히트 이펙트

| 충돌 대상 | 이펙트 |
|---|---|
| 몬스터 | 기존 혈흔 VFX (유지) |
| 벽 / 장애물 | 금속 반짝임 파티클 (SparkOnContact) — 흰색~주황색 |
| 지면 | 먼지 파티클 (미구현, Phase 2 예정) |

- 무기 히트박스 "Obstacle" / "Wall" 레이어 충돌 시 발동
- `WeaponEffectHandler`에서 레이어 판별 후 파티클 스폰

## 10.4 공격 전진성 (Forward Momentum)

공격 입력 시 캐릭터가 타격 방향으로 짧게 전진:

- 공격 진입 시 `Rigidbody.AddForce(forward × attackDashForce, Impulse)`
- 빠르게 느껴지는 타격감 확보 ("칼이 적을 향해 뻗어나가는" 느낌)
- 기본값: `attackDashForce` = 3.0 (무기 데이터 SO에서 조정 가능)

## 10.5 이동 중 공격 관성 (Attack Inertia)

이동 중 공격 입력 시 즉시 멈추지 않고 점진 감속:

- 공격 진입 시 현재 MoveScale을 기록
- 공격 지속 중 MoveScale이 0.25초에 걸쳐 0으로 선형 감소
- 공격 종료 후 MoveScale 1.0 복원
- 결과: 달리다 베는 동작이 자연스럽게 느려지며 타격

## 10.6 플레이어 → 몬스터 넉백

공격 적중 시 몬스터를 피격 방향 반대로 밀어냄:

- 넉백 거리: 무기별 `knockbackToMonster` 수치 (WeaponData SO)
- 구현: `NavMeshAgent` 일시 비활성화 → `NavMeshAgent.Warp()`로 위치 이동 → 재활성화
- **슈퍼아머 엘리트**: 넉백 면역 (8.4.1 참조)

## 10.7 회피로 장애물 통과

구르기(Dodge) 중 장애물 충돌 무효화:

- 구르기 진입 시 플레이어 레이어 → `PlayerDodge`
- Physics Matrix: `PlayerDodge ↔ Obstacle` = 충돌 없음
- 구르기 종료 시 레이어 `Player`로 복원
- **통과 불가 대상**: 방 외곽 벽 (`Wall` 레이어는 충돌 유지)

## 10.8 사망 화면

플레이어 HP 0 시 시퀀스:

1. 블랙 페이드 오버레이 (0.5초 암전)
2. Cinemachine 카메라 → 캐릭터 클로즈업 줌인 (2~3초)
3. **"다시하기 / 포기"** UI 표시
   - 다시하기: §3.2 저장 규칙에 따라 선택한 방 입구부터 재진입
   - 포기: 허브(로비)로 복귀, 런 결과 정산

# 11. 튜토리얼 & 온보딩

## 11.1 첫 런 튜토리얼 플로우

게임 최초 실행 시 자동 진입 (저장값 `TutorialDone = 0`):

```
[스타트방 자동 진입]
  ↓ 약한 초기 캐릭터 + 튜토리얼 기본 장비로 시작
  ↓ 가이드 텍스트 UI로 기본 조작 안내 (이동/공격/회피/스킬)
  ↓ 플레이어 사망 (의도적 낮은 스펙 — 튜토리얼 관문)
  ↓ 멀린 컷씬 재생
      멀린: "영혼이여... 내가 힘을 불어넣어 주겠다.
             이 유물들 중 하나를 골라라."
  ↓ 허브(로비) 진입 → 캐릭터 선택 + 장비 선택 활성화
  ↓ 일반 런 시작
[TutorialDone = 1 저장]
```

> 튜토리얼은 강제 사망으로 허브 진입을 유도. 이후 멀린이 안내하는 형태로 메타 시스템 소개.

## 11.2 스타트방 구성 (Zone 1, 고정)

모든 런의 첫 방은 전투 없는 준비 공간:

| 요소 | 내용 |
|---|---|
| **확정 특별 아이템** | 런 난이도 기준 맞춤 Common~Rare 1개 확정 드롭 |
| **더미 / 약한 몬스터** | 소형 몬스터 1~2마리 또는 연습용 더미 (조작 체험) |
| **멀린 의지 환영 대사** | 스타트방 진입 시 한 줄 환영 + 진행 안내 |
| **장비 확인 공간** | 스탯 패널 확인 가능, 무기 교체 기회 |

## 11.3 가이드 텍스트 UI

화면 상단/중앙에 2~3초 표시되는 힌트 텍스트 (튜토리얼 런에서만 자동 활성):

| 시점 | 텍스트 |
|---|---|
| 방 입장 직후 | "WASD로 이동 / 마우스 좌클릭으로 공격" |
| 첫 회피 유도 | "Shift(스페이스)로 구르기 — 장애물도 통과 가능" |
| 스킬 언락 후 | "Q / E 키로 스킬 사용" |
| 아이템 획득 후 | "Tab 키로 아이템 그리드 열기 — 배치해야 효과 발동" |

## 11.4 로비 캐릭터 & 장비 전시대

하데스(Hades) 스타일 허브 UI:

### 캐릭터 전시대
- 해금된 영웅 유물이 3D 모델로 회전 전시
- 선택 시: 스탯 / 고유 패시브 / 고유 스킬 정보 패널 표시
- **"연습" 버튼**: 더미가 배치된 샌드박스 방으로 즉시 진입 (런 시작 아님)
  - 조작 감각 확인, 콤보/스킬 테스트 용도
  - 나가면 허브로 복귀

### 장비 전시대
- 보유 무기가 3D 모델로 전시
- 선택 시: 기본 공격 방식 / 스킬 슬롯 / 스탯 수치 표시
- 영웅별 **친화도 배지** 표시 (★★★ 최고 시너지 조합)
- 최대 2슬롯 장비 선택 (기존 무기 선택 시스템과 연동)
