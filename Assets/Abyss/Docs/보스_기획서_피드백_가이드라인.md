# 보스 기획서 2.0v 피드백 가이드라인

> 대상 문서: 보스 기획서 2.0v (왕의 정원 파수꾼)
> 작성일: 2026-04-17
> 목적: 기획서 보완 요청 사항 정리

---

## 1. 수치 데이터 부재

현재 기획서에 구체적인 수치가 전부 빠져 있음. 아래 항목 필수 추가 요망.

| 누락 항목 | 비고 |
|---------|------|
| 보스 HP (1페이즈/2페이즈 총합) | 플레이어 DPS 기준 예상 클리어 타임과 함께 산출 |
| 패턴별 데미지 | 플레이어 HP 대비 비율로 명시 (예: 펀치 = 플레이어 HP의 8%) |
| 강인도 게이지 최댓값 | 정수 기준 (예: 100) |
| 강인도 감소량 (강공격/스킬별) | 패턴별 차등 필요 |
| 강인도 자연 회복 속도 | 초당 수치 명시 (예: 3초 미피격 시 초당 5 회복) |
| 패턴 가중치 기본값/최댓값 | 패턴별 개별 설정 |
| 가중치 회복 속도 | "5~10초간 서서히 회복"이 아닌 정확한 곡선 또는 초당 수치 |

수치 없으면 개발자가 임의로 넣게 되고, 밸런싱 책임 소재가 불명확해짐.

## 2. 이동/행동 설계 전면 부재 (가장 큰 문제)

현재 기획서는 **공격 패턴 카탈로그**임. 보스가 공격하지 않는 시간(전체의 60~70%)에 대한 행동 설계가 없음.

### 2-1. 기본 대치 행동 (Idle Combat) 추가 필요

- 플레이어와 대치 시 보스의 이동 방식
  - 원형 서클링? 좌우 스텝? 전진/후퇴 반복? 제자리 고정?
- 보스의 **선호 교전 거리** 명시
  - 예: 1페이즈 선호 거리 5m, 2페이즈 선호 거리 3m
- 플레이어 tracking 방식
  - 항상 정면을 향하는가? 회전 속도 제한이 있는가?
- 이동 시 연출 특성
  - 묵직한 발걸음? 나무 질감 특유의 삐걱거림? 지면 흔들림?

### 2-2. 접근 행동 (Approach) 추가 필요

플레이어가 원거리에 있을 때 보스가 거리를 좁히는 방법.

- 느린 위압 접근 (걸어오기)
- 짧은 스텝 점프로 간격 좁히기
- 돌진으로 즉시 진입
- 접근 중 페인트 (다가오다 멈추기, 방향 전환)
- 페이즈별 접근 성향 차이

### 2-3. 공격 후 행동 (Post-Attack) 추가 필요

각 패턴이 끝난 직후 보스가 취하는 행동. 현재 돌진 후 1.5초 경직만 언급되어 있고 나머지는 전부 비어 있음.

| 패턴 | 공격 후 행동 (예시, 기획자가 확정 필요) |
|------|---------------------------|
| 펀치 | 제자리 유지? 한 발 후퇴? |
| 내려 찍기 | 경직 유무? 바로 후속 가능? |
| 회전 킥 | 어지러움 연출? 즉시 행동 전환? |
| 돌진 | 벽 충돌 시 추가 경직? 그냥 멈춤? |
| 돌 던지기 | 던진 후 접근 시도? 대기? |
| 잡아 던지기 | 던진 후 추격? 도발 모션? |
| 브레스 | 방사 후 과열 경직? |
| 땅 가르기 | 팔 뽑는 후딜? |

**이 테이블이 곧 플레이어의 딜타임 설계**임. 반드시 채워야 함.

### 2-4. 거리 벌리기 (Disengage) 추가 필요

현재 거리 벌리기 수단이 **파고들기** 하나뿐임.

- 일반 후퇴 수단 추가 필요 (백스텝, 밀어내기 등)
- 후퇴 후 멈추는 거리 명시 (중거리? 원거리?)
- 후퇴 후 선택 가능한 행동 분기
  - 돌 던지기로 견제 → 돌진으로 재진입
  - 대치하며 서클링 → 타이밍 보고 접근
  - 즉시 재돌진 (2페이즈 한정)
- 페이즈별 후퇴 빈도/성향 차이

## 3. 페이즈별 행동 성격 정의 필요

현재 1페이즈와 2페이즈의 차이가 **수치 강화**에 그침. 보스의 행동 "성격"을 정의해서 체감 차이를 만들어야 함.

### 요청 포맷

| 항목 | 1페이즈 | 2페이즈 |
|------|--------|--------|
| 전투 성격 | 예: 수호자 (대기 → 반격) | 예: 포식자 (압박 → 몰아붙이기) |
| 선호 교전 거리 | ? | ? |
| 접근 성향 | ? | ? |
| 공격 후 행동 경향 | ? | ? |
| 후퇴 빈도 | ? | ? |
| 대치 중 이동 패턴 | ? | ? |

페이즈 전환 시 플레이어가 **"얘가 달라졌다"**를 수치가 아닌 행동으로 느껴야 함.

## 4. 공방 리듬 (Attack-Defense Rhythm) 설계 부재

플레이어가 **언제 때리고, 언제 피해야 하는지**가 명시되지 않음. 아래 포맷으로 패턴별 공방 흐름 정리 필요.

```
[전조 모션] → [공격 판정] → [후딜/경직] → [플레이어 딜타임]
  Xms          Xms          Xms           X초
```

예시:
```
돌진: 준비 모션 0.5초 → 돌진 1.5초 → 중심잡기 1.5초 → 딜타임 1.5초
내려 찍기: 팔 올리기 0.6초 → 찍기 0.2초 → 충격파 0.8초 → 딜타임 0.8초
```

각 패턴마다 이 시퀀스가 있어야 전투 리듬이 설계된 것임.

## 5. 반응형 행동(Step 2) 설계 의도 보충 필요

| 상황 | 선택 행동 | 확률 (1페/2페) |
|------|---------|-------------|
| 차징 사용 중 | 도약 | 30% / 60% |
| 강인도 20% 이하 | 파고들기 | 50% / 80% |
| 3회 연속 피격 | 목질 강화 | 40% / 70% |

문제점:
- 이 확률의 **산출 근거**가 없음. 왜 30%인지, 왜 60%인지
- **플레이어에게 주려는 경험**이 뭔지 설명 없음
  - 차징을 쓰면 보스가 피하니까 → 차징 남발을 막으려는 건지?
  - 아니면 차징의 리스크/리턴을 만들려는 건지?
- 확률이 아닌 **조건부 확정**이 더 나은 케이스가 있을 수 있음 (예: 강인도 10% 이하면 파고들기 100%)

각 반응 행동에 **"이걸 통해 플레이어가 느끼길 원하는 것"**을 한 줄씩 추가할 것.

## 6. 파고들기 트리거 조건 불일치

현재 기획서 내에서 파고들기 발동 조건이 두 군데에서 다르게 적혀 있음.

- **Step 2 (p5)**: "강인도가 30% 이하일 때" → 파고들기
- **패턴 상세 (p10)**: "체력이 짧은 시간 내에 일정량 이상 깎일 때" → 파고들기

**어느 쪽이 맞는지 확정**하고, 수치도 구체화할 것.
- "짧은 시간" → 몇 초?
- "일정량" → HP의 몇 %?

## 7. 전투 공간 사양 부재

보스전 기획에 전투 공간 정보가 없음.

필수 추가 항목:
- **보스 방 크기** (가로 x 세로, 또는 반경)
  - 돌진 사거리 20m인데 방이 25m면 벽 충돌 처리 필요
  - 방이 50m면 돌진이 허공에서 끝남
- **지형 특성**: 평지? 장애물? 기둥?
- **벽 충돌 시 보스/플레이어 행동**
- **"왕의 정원"이라는 설정이 전투에 어떻게 반영되는지**
  - 나무/덩굴 장애물? 파괴 가능 오브젝트? 순수 연출?

## 8. 미결정 항목을 기획서에 포함하지 말 것

현재 기획서 마지막 페이지:
> "고민중: 엇박자 선 딜레이, 공격 타이밍 전조 방식"

이 두 항목은 **보스전 체감의 핵심**임. 미결정 상태로 기획서를 제출하면 안 됨.

- **엇박자 선 딜레이**: 랜덤 범위를 확정하고, 어떤 패턴에 적용할지 명시
- **전조 방식**: 장판 vs 모션 각각의 장단점 비교 후 결정. 패턴별로 다를 수 있음

결정이 어려우면 **A안/B안 비교표**를 만들어서 제출. "고민중"으로 넘기지 말 것.

## 9. 페이즈 전환 연출 상세화 필요

현재 내용: "폼 변경 모션 재생, 공격 불가, 3초 소요"

추가 필요:
- 전환 중 플레이어 공격 가능 여부 (무적? 슈퍼아머? 피격 가능?)
- 전환 모션 중 넉백/밀어내기 판정 유무
- 전환 완료 후 보스의 첫 행동 (즉시 공격? 포효 연출? 대치?)
- 전환 트리거: HP 50% 도달 즉시? 진행 중인 패턴 완료 후?
