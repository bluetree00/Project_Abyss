# 2. 세계관 & 시나리오

## 2.1 배경 설정

아서왕 전설의 세계. 최고의 마법사 **멀린**이 의문의 외부 존재에 의해 살해된다.
그의 죽음과 동시에 세계는 부패하기 시작하고, 자연 · 고대 존재 · 인간 영웅들이 차례로 잠식된다.

멀린의 잔존 의지는 사후에도 흩어지지 않고 하나의 목적으로 수렴한다.
**"근원을 찾아라. 세상을 정상화하라."**

그는 세계 너머에서 **신성한 영혼**을 소환하고, 쓰러진 영웅들의 유물(육체)을 그 그릇으로 삼는다.
주인공은 영혼이다. 형체는 없다. 하지만 유물을 빌리면 싸울 수 있다.

> **모던 다크 동화 톤**
> 밝고 귀여운 동화가 아니다. 한때 빛났던 이야기가 부패하고 잠식된 세계.
> 잔해만 남은 동화책의 마지막 페이지 같은 분위기.

## 2.2 핵심 인물

### 멀린 (Merlin)
- 세계 최고의 마법사, 아서왕의 스승
- 게임 시작 시점에는 이미 사망
- **잔존 의지**로만 존재하며 주인공을 안내
- 런마다 돌아오는 허브 공간에서 목소리로 대화
- 진행하면서 점점 약해지다가 마지막에 진실을 고백

### 주인공 (신성한 영혼)
- 이름·형체 없음. 플레이어가 곧 영혼
- 멀린의 소환으로 세계에 존재
- 영웅의 유물(육체)을 빌려 전투
- 사망 시 멀린의 의지가 복구 → 재도전

### 모드레드 (Mordred) — 챕터 3 보스
- 원탁의 기사였으나 타락한 배신자
- 아서왕 전설에서도 아서를 배신한 인물
- 리치에게 잠식되기 전부터 어둠을 품었던 존재
- 영웅들 중 가장 먼저 리치의 도구가 된 자

### 리치 (The Lich) — 최종 보스
- 멀린의 육체를 탈취한 외부 존재
- 멀린의 전성기 마법 능력을 그대로 복사
- 세계 부패의 실질적 근원
- 쓰러지기 전 모르가나의 존재를 암시

### 모르가나 (Morgan le Fay) — 포스트 엔딩 암시
- 멀린의 제자이자 숙적
- 리치를 통해 멀린의 육체를 도구로 활용한 진짜 배후
- 리치 격파 후 목소리로만 등장 — 다음 챕터 암시

## 2.3 서사 아크 — 챕터별 빌드업

### 챕터 1 — 부패의 숲

**테마**: 혼돈, 원인 불명
**서사**: 세계가 이상하다는 것을 인지하는 단계. 멀린의 의지가 명확하게 주인공을 안내한다.

> *멀린의 의지: "영혼이여, 내가 힘을 불어넣어 주겠다. 근원을 찾아라."*

- 숲의 자연 수호자들이 부패
- 그린 나이트가 숲을 지배
- 영웅 유물 첫 발견 — "이 영웅은 왜 쓰러졌는가?"

**챕터 보스**: 그린 나이트 (The Green Knight)
- *가웨인과 녹색 기사* 전설의 인물
- 숲의 수호자가 부패로 거대화된 형태
- 가웨인 암시 유물을 사용하는 플레이어에게 특별 대사 출력

---

### 챕터 2 — 용암 대지

**테마**: 규모 확대, 부패의 깊이
**서사**: 고대 존재까지 잠식됐음을 확인. 멀린의 의지가 불안해지기 시작한다.

> *멀린의 의지: "이 부패는... 의지를 가지고 있어. 단순한 확산이 아니야."*

- 고대 용이 부패의 에너지에 잠식
- 영웅의 유물에서 기억 파편 발견 — "우리는 싸우다 쓰러진 게 아니라 — 당했다"

**챕터 보스**: 이 드레이그 고흐 (Y Ddraig Goch)
- 멀린이 직접 예언한 웨일스의 붉은 용
- 멀린이 예언했던 존재가 부패의 도구가 된 아이러니
- 격파 후 멀린: *"내가 예언한 존재가... 이렇게 쓰이다니."*

---

### 챕터 3 — 잠식된 성채

**테마**: 공포, 배후의 실체화
**서사**: 인간 영웅이 잠식됐음을 처음 목격. 리치의 직접 개입 흔적 발견.

> *멀린의 의지: "내 기억이 흐릿해지고 있어. 뭔가가 나를 갉아먹는 것 같아..."*

- 성채 전체가 리치의 부패 에너지로 점령
- 영웅들의 힘이 복사되고 있다는 단서 발견
- 리치가 의도적으로 영웅들을 분석·복사해왔음 확정

**챕터 보스**: 모드레드 (Mordred)
- 원탁의 기사, 리치에게 잠식된 배신자
- 격파 후 잠시 의식을 되찾으며 단서 제공
- *"그 자는... 모든 것을 복사했어. 너희까지도..."*

---

### 챕터 4 — 암흑대지 (최종)

**테마**: 근원, 비극적 클라이맥스
**서사**: 모든 진실이 드러나고 주인공이 최대 위기에 직면한다.

```
입장
  → 역대 영웅 복사체 연속전 (플레이어가 써온 유물의 복사체 포함)
  → 멀린의 마지막 메시지 재생
  → 리치 (멀린의 육체) 최종 보스전
  → 엔딩 + 모르가나 암시
```

**최종 챕터 직전 멀린의 대사**:
> *"알아냈어. 내 육체가... 잠식됐어."*
> *"부탁해. 막아줘."*

**리치 격파 후 엔딩**:
> 리치가 쓰러지며 마지막으로 웃음
> *"...멍청한 영혼. 이건 시작에 불과했는데."*
>
> 어딘가에서 모르가나의 목소리:
> *"잘했어. 실험은 끝났으니까."*
>
> 멀린의 의지 (희미하게):
> *"모르가나... 역시 그녀였군. 아직... 끝나지 않았어."*

## 2.4 멀린의 의지 — 내러티브 엔진

멀린의 의지 상태가 런 진행에 따라 변화하며 게임의 서사 온도를 조율한다.

| 런 구간 | 멀린 상태 | 허브 분위기 | 대사 톤 |
|---|---|---|---|
| 1~10런 | 강하고 명확 | 탑 잔해, 희미한 빛 | 단호하고 목적적 |
| 10~30런 | 불안, 단편적 | 빛이 줄어듦 | 걱정, 혼란 |
| 30~50런 | 희미해짐 | 탑이 더 어두워짐 | 쉰 목소리, 끊김 |
| 최종 챕터 | 마지막 각성 | 한순간 밝아짐 | 간절하고 절박함 |

# 3. 코어 게임 루프

## 3.1 거시적 루프

```
[허브: 멀린의 탑 잔해]
        ↓ 영웅 유물 + 장비 선택
[런 시작]
        ↓ 방 탐색 + 전투
[챕터 1~4 진행]
        ↓ 사망 또는 클리어
[허브 복귀]
        ↓ 재화 소비 (서약/해방/각성)
[강해진 영혼으로 재도전]
```

## 3.2 미시적 루프 (인게임)

```
[방 입장]
    → 방 버프 선택 (3~5개 중 1개)
    → 전투 수행
    → 아이템 획득 → 그리드 배치
    → 방 클리어 보상 (골드/아이템/봉인된 기억)
    → 다음 방 선택 (노드 맵)
[보스방]
    → 보스 처치 → 유물 코어 획득 (첫 격파 시)
    → 다음 챕터 또는 엔딩
```

## 3.3 씬 구성

| 씬 | 역할 |
|---|---|
| **로그인** | 계정 인증 |
| **로비** | 영웅 유물 선택, 장비 선택, 멀린의 서약 접근 |
| **스테이지맵** | 노드 기반 방 선택 |
| **게임씬** | 실제 전투 |
| **결과** | 런 결과, 재화 정산 |

# 4. 영웅 유물 시스템

## 4.1 시스템 개요

> "영웅의 이름은 잊혀졌다. 남은 건 유물뿐이다."

- 영웅 유물 = 쓰러진 영웅의 육체
- 정체는 **패시브 이름·스킬 이름·고유 대사**로만 암시
- 플레이어가 직접 유추하는 재미
- 모든 영웅이 모든 장비 사용 가능
- 영웅마다 **고유 패시브 + 고유 스킬 + 고유 메커닉** 보유

## 4.2 영웅별 상세 설계

---

### 유물 1 — [성배의 수호자] `기본 제공`

> 암시: 갈라하드 (Galahad) — 원탁에서 가장 성스러운 기사, 성배를 완성한 유일한 존재

**스타일**: 방어형 / 초보 친화 / 진입장벽 낮음

#### 기본 스탯
| 스탯 | 수치 |
|---|---|
| 기본 HP | 150 |
| 기본 공격력 | 80 |
| 기본 방어력 | 40 |
| 이동속도 | 표준 (1.0x) |

#### 고유 패시브
| 패시브명 | 효과 |
|---|---|
| **성스러운 방패** | 방어 입력 시 받은 피해의 30%를 전방 적에게 반사 |
| **아버지의 죄** | 피격 시 신성 게이지 +15 충전. 방어 성공 시 +25 충전 |

#### 고유 스킬: **성배의 빛**
- 쿨다운: 18초
- 효과: 전방 4m 범위 신성 폭발. 피해량 공격력 × 180%
- 신성 게이지 30 이상일 때 사용 시 범위 +50%, 피해량 +50%

#### 고유 메커닉: **신성 게이지**
```
최대 게이지: 100
충전:
  피격 시 +15
  방어 입력 성공 시 +25
  성배의 빛 사용 시 +20

만충(100) 달성 시:
  → 5초간 무적 + 공격력 150% + 신성 게이지 빛 연출
  → 이후 30초 쿨다운 (재충전 불가)
```

#### 메커닉 변형 아이템 예시
| 아이템명 | 효과 |
|---|---|
| *죄의 대가* | 공격 시에도 게이지 +8 충전 → 공격형 전환 |
| *성배의 축복* | 게이지 50마다 소폭 효과 발동 (무적 없이) → 지속형 |
| *순교의 서약* | 게이지 만충 효과 지속시간 5초 → 10초 |

---

### 유물 2 — [원탁의 균열] `봉인된 기억 3개`

> 암시: 랜슬롯 (Lancelot) — 원탁 최강의 기사, 금지된 사랑으로 원탁을 무너뜨린 비극의 존재

**스타일**: 고속 공격형 / 콤보 집중 / 중~고 난이도

#### 기본 스탯
| 스탯 | 수치 |
|---|---|
| 기본 HP | 120 |
| 기본 공격력 | 110 |
| 기본 방어력 | 20 |
| 이동속도 | 빠름 (1.2x) |

#### 고유 패시브
| 패시브명 | 효과 |
|---|---|
| **금지된 맹세** | 콤보 스택 1개당 공격력 +3% (최대 20스택 = +60%) |
| **원탁의 균열** | 처치 시 1.5초간 이동속도 +25% |

#### 고유 스킬: **최강의 일격**
- 쿨다운: 22초
- 효과: 0.3초 무적 후 단일 극딜 타격. 피해량 공격력 × 350%
- 현재 콤보 스택 수가 높을수록 피해량 증가 (스택당 +5%)

#### 고유 메커닉: **콤보 게이지**
```
최대 스택: 20
충전:
  공격 1회당 +1 스택
  스킬 사용 시 +3 스택

초기화 조건:
  1.5초 이상 공격 미실시
  피격 시 현재 스택 -5

효과:
  스택 1~9:  공격력 +3% × 스택수
  스택 10~19: 추가로 이동속도 +10%
  스택 20 도달: 공격력 +60% + 이동속도 +20% + 이펙트
```

#### 메커닉 변형 아이템 예시
| 아이템명 | 효과 |
|---|---|
| *분노의 맹세* | 피격 시에도 스택 +3 충전 → 탱킹 빌드 전환 |
| *고독한 검* | 처치 시 스택 +8 충전, 공격당 충전량 삭제 → 암살 빌드 |

# 5. 장비 & 빌드 시스템

## 5.1 장비 구조

모든 영웅이 모든 장비 사용 가능.
장비 = 액티브 스킬셋 + 기본 공격 방식 결정.

| 장비 유형 | 공격 스타일 | 특징 |
|---|---|---|
| **카타나** | 고속 연속기 | 짧은 사거리, 높은 공격 속도 |
| **대검** | 강타형 | 긴 사거리, 낮은 공격 속도, 높은 단타 피해 |
| **창** | 돌진/관통형 | 직선 관통, 중간 속도 |
| **활** | 원거리 | 긴 사거리, 투사체 |
| **검+방패** | 방어형 | 방어 기능 포함, 균형 스탯 |

## 5.2 아이템 이중 효과 구조

모든 아이템은 **범용 효과 + 영웅 친화 보너스** 두 줄 보유.

```
[분노의 맹세]
─────────────────────────
기본 효과:   공격력 +10%
─────────────────────────
원탁의 균열 친화:
  피격 시 콤보 게이지 +3 충전
─────────────────────────
```

- 범용 효과: 어떤 영웅이든 장착 가능
- 친화 보너스: 해당 영웅 장착 시만 발동
- 드롭 풀: 현재 영웅의 메커닉 기준 **가중치 조정** (친화 아이템 30% 상향)

## 5.3 영웅 × 장비 × 메커닉 조합표

| | 카타나 | 대검 | 창 | 활 | 검+방패 |
|---|---|---|---|---|---|
| **성배의 수호자** | 공격으로 게이지 충전 어려움 | 강타 후 피격 유도 → 탱딜 | 표준 | 원거리 게이지 지연 | 방어+게이지 최적 ★ |
| **원탁의 균열** | 콤보 빠른 충전 ★ | 리스크 고보상 | 돌진 콤보 | 안전 딜링 | 방어적 콤보 |
| **여정의 창** | 빠른 처치 → 스택 누적 | 보스킬러 빌드 ★ | 돌진+스택 시너지 ★ | 안전 누적 | 균형형 |
| **태양의 서약** | 강화 구간 연속딜 | 강화 구간 강타 ★ | 강화 구간 돌진 | 원거리 버스트 | 방어 유지 ★ |
| **비련의 화살** | 근접 → 거리 페널티 위험 | 근접 → 페널티 최고위험 | 히트앤런 | 거리 최적 ★ | 방어로 근접 방지 |

★ = 높은 시너지 조합

# 6. 런 내 성장 시스템

## 6.1 스탯 레이어 구조 (7단계 합산)

```
최종 스탯 =
  [1] 기본 (영웅 유물 기본 스탯)
+ [2] 서약 (멀린의 서약 영구 보너스)
+ [3] 유물 각성 (해금된 각성 효과)
+ [4] 장비 (선택한 장비 스탯)
+ [5] 아이템 (그리드 배치된 아이템 합산)
+ [6] 방버프 (현재 활성 방버프)
+ [7] 시너지 (그리드 시너지 Always/조건부)
```

## 6.2 아이템 시스템

### 아이템 획득 ~ 효과 적용 흐름
```
적 처치 또는 방 보상
  → 아이템 드롭 (등급별 확률)
  → Staging(임시 보관) — 효과 없음
  → 플레이어가 그리드에 배치
  → ItemEffectManager.Rebuild()
  → 효과 발동
```

### 아이템 등급 및 드롭 확률

| 등급 | 기본 확률 | 효과 특성 |
|---|---|---|
| Common | 55% | 범용 스탯 보정 |
| Rare | 30% | 조건부 효과 + 영웅 친화 보너스 |
| Epic | 12% | 메커닉 변형 |
| Legendary | 3% | 빌드 완전 전환 |

> 멀린의 서약 "아이템 등급 상승" 항목 보유 시 확률 조정
> 럭(Luck) 스탯이 높을수록 Rare 이상 확률 증가

### 아이템 효과 트리거 종류

| 트리거 | 발동 조건 |
|---|---|
| Always | 배치 즉시 영구 적용 |
| OnHit | 공격 적중 시 발동 |
| OnKill | 적 처치 시 발동 |
| OnRoomClear | 방 클리어 시 발동 |
| OnLowHp | HP 30% 이하 시 발동 |
| OnBossClear | 보스 처치 시 발동 |

## 6.3 그리드 시너지

아이템의 `shapeId`에 따라 퍼즐 보드에 블록 배치. 그리드 완성 시 시너지 발동.

### 시너지 트리거

| 트리거 | 조건 | 효과 방식 |
|---|---|---|
| **Always** | 그리드 완성 즉시 | 스탯 영구 반영 |
| **OnHit** | 공격 적중 시 스택 누적 | 최대 스택까지 누적, duration 초 유지 |
| **OnLowHp** | HP ≤ threshold | 조건 만족 시 활성화 |

### 그리드 완성 보상 예시

| 시너지명 | 트리거 | 효과 |
|---|---|---|
| *기사의 각오* | Always | 공격력 +15% |
| *원탁의 결속* | Always | MaxHP +50 |
| *심판의 일격* | OnHit | 스택당 공격력 +2% (최대 10스택) |
| *사지의 저항* | OnLowHp | 방어력 +40%, 이동속도 +15% |

## 6.4 방 버프

### 구조
- 방 입장 시 버프 3~5개 제시 → 1개 선택
- 최대 10슬롯 (초과 시 가장 오래된 버프 제거)
- 방 퇴장마다 남은방 수 -1 → 0이 되면 자동 제거

### 버프 등급

| 등급 | 지속 방 수 | 효과 강도 |
|---|---|---|
| Tier 1 | 3방 | 기본 |
| Tier 2 | 4방 | ×1.5 |
| Tier 3 | 5방 | ×2.0 |

> 보스 처치 시 보유 중인 모든 버프 **Tier +1 승급 + 남은방 수 리셋**

### 버프 예시

| 버프명 | 효과 |
|---|---|
| *전사의 각오* | 공격력 +20% (Tier 1 기준) |
| *철벽의 의지* | 방어력 +25% |
| *영혼의 회복* | 방 클리어 시 HP 5% 회복 |
| *기사의 발걸음* | 이동속도 +15% |
| *저주의 낙인* | 받는 피해 +20% 대신 공격력 +50% (디버프 버프) |

## 7.4 유물 각성 (유물 코어 소비)

> "유물이 진짜 이름과 힘을 되찾는다. 영웅의 진정한 각성."

각 영웅 유물마다 Tier 1~3 각성 존재. 각성할수록 고유 메커닉이 심화된다.

| 각성 Tier | 필요 유물 코어 | 효과 방향 |
|---|---|---|
| Tier 1 | ×1 | 메커닉 수치 강화 |
| Tier 2 | ×2 | 메커닉에 새로운 조건 추가 |
| Tier 3 | ×3 | 메커닉 근본 확장 |

### 성배의 수호자 각성 예시

| 각성 | 효과 |
|---|---|
| Tier 1 | 신성 게이지 만충 효과 지속 5초 → 8초 |
| Tier 2 | 신성 게이지 50% 이상 시에도 소폭 효과 발동 (무적 없이, 공격력 +30%) |
| Tier 3 | 신성 게이지 만충 후 쿨다운 중에도 피격 시 게이지 소량 재충전 가능 |

## 8.2 챕터 타일 맵 시스템

> ⚠️ **[고민 단계]** 아래 내용은 확정되지 않은 설계 방향입니다.
> 현재 검토 중인 구조: **단일 피라미드형(12~20타일)** vs **2구역 분기형(16타일)**
> - 단일 피라미드: 직선 최단 경로 문제 → 멀린 의지 게이지로 탐색 강제 검토 중
> - 2구역 분기형: 구역A + 구역B 각각 미니보스 → 둘 다 클리어 시 최종 보스 개방
> 방향 결정 후 이 섹션을 업데이트 예정.

### 핵심 컨셉

> **"전체 맵이 처음부터 보인다. 단, 모든 길은 막혀 있다."**
>
> 챕터 시작 시 12개의 타일이 전체 공개된다.
> 시작 타일 외 모든 타일은 챕터 테마에 맞는 장애물로 봉인되어 있다.
> 방을 클리어하면 멀린의 의지가 인접 타일의 장애물을 걷어낸다.
> 플레이어는 열린 타일의 정보를 보고 다음 행선지를 선택한다.

---

### 12타일 구조

각 챕터는 고정된 12개의 타일로 구성된다.
타일의 **물리적 레이아웃(공간 구조)**은 CSV 테이블로 미리 정의되어 있으며,
**방 컨셉(전투/상점/이벤트 등)**은 런 시작 시 랜덤으로 배정된다.

```
            [ 12 ]          ← 보스방 (고정)
          [ 10 ][ 11 ]
        [ 7 ][ 8 ][ 9 ]
        [ 4 ][ 5 ][ 6 ]
          [ 2 ][ 3 ]
            [  1 ]          ← 시작방 (고정)
```

- 타일 1: 시작방 (항상 고정, 장애물 없음)
- 타일 12: 보스방 (항상 고정, 마지막에만 접근 가능)
- 타일 2~11: 런마다 컨셉 랜덤 배정

---

### 타일 상태 정의

| 상태 | 설명 | 플레이어 표시 |
|---|---|---|
| **Sealed** | 장애물로 봉인됨 | 장애물 이펙트만 표시, 컨셉 비공개 |
| **Available** | 인접 방 클리어로 개방 가능 상태 | 컨셉 아이콘 + 예상 보상 공개 |
| **Selected** | 플레이어가 선택, 멀린 상호작용 중 | 개방 연출 재생 |
| **Active** | 현재 플레이 중인 방 | 하이라이트 |
| **Cleared** | 클리어 완료 | 완료 표시 |

---

### 챕터별 장애물 테마

| 챕터 | 배경 | 장애물 | 시각 표현 |
|---|---|---|---|
| 1 | 부패의 숲 | **물 (Water)** | 범람한 흑수(黑水), 부패한 강이 길을 막음 |
| 2 | 용암 대지 | **용암 (Lava)** | 흐르는 용암류, 화산재 장벽 |
| 3 | 잠식된 성채 | **안개 (Fog)** | 마법 안개, 시야 차단형 |
| 4 | 암흑대지 | **공허 (Void)** | 공허의 균열, 허공에 갈라진 틈 |

---

### 런 시작 시 맵 생성 흐름

```
런 시작
  ↓
챕터 타일 배치 테이블 로드 (12개 타일 위치, 연결 정보)
  ↓
각 타일에 물리 레이아웃 배정 (CSV 풀에서 선택)
  ↓
각 타일에 방 컨셉 랜덤 배정 (아래 분포 참고)
  ↓
타일 1 = Available, 타일 2~12 = Sealed 상태로 초기화
  ↓
플레이어 맵 진입
```

| 방 컨셉 | 고정 수량 | 내용 |
|---|---|---|
| **시작방** | 1 (고정) | 준비 공간, 전투 없음 |

| **보스방** | 1 (고정) | 챕터 보스 |

> 챕터 4는 보스방 이전에 **영웅 복사체 방** 1개 추가 (이벤트방 대체)

```

  ↓

  ↓
```

### CSV 타일 레이아웃 구조 (설계 기준)

물리 레이아웃(CSV)과 방 컨셉은 분리되어 관리됨.
동일한 CSV 레이아웃(바닥 구조, 스포너 위치, 진입구 형태)이 전투방에도, 상점방에도 사용될 수 있음.

| 레이아웃 필드 | 역할 |
|---|---|
| `layout_id` | 레이아웃 고유 키 |
| `theme` | 시각 테마 (숲/용암/성채/암흑) |
| `grid_csv` | 타일 그리드 (바닥/벽/스포너 위치 등) |
| `entrance_type` | 진입구 형태 (Dissolve/Scatter 등) |
| `width / height` | 방 크기 |

컨셉(`concept`)은 레이아웃과 별도로 런 시작 시 배정되며, 몬스터 구성/상점 여부/이벤트 스크립트를 결정함.

## 9.1 아트 방향성

**모던 다크 동화 (Modern Dark Fairy Tale)**

> 한때 빛났던 동화의 페이지가 잠식되고 부패한 세계.
> 귀엽거나 밝지 않다. 어둡고 잔인하지만 아름다운 잔재가 남아있다.

| 요소 | 방향 |
|---|---|
| **색감** | 채도 낮은 어두운 팔레트. 포인트 컬러로 신성한 금빛·청백 사용 |
| **배경** | 부패한 자연 + 중세 건축 잔해. 완전히 파괴되지 않은 "한때 아름다웠던" 느낌 |
| **캐릭터** | 실루엣 중심. 영웅 유물은 갑옷·외형에서 원작 힌트만 남김 |
| **UI** | 고딕 라인 기반 모던 미니멀. 과도한 장식 없이 정보 중심 |
| **이펙트** | 신성 게이지는 금빛, 부패 에너지는 보라·흑색, 불꽃은 붉은 주황 |

## 9.2 챕터별 비주얼 톤

| 챕터 | 메인 컬러 | 분위기 |
|---|---|---|
| 부패의 숲 | 탁한 초록, 검은 보라 | 생명이 부패한 숲. 덩굴이 건물을 삼킴 |
| 용암 대지 | 붉은 주황, 검정 | 고대 지형이 용암으로 뒤덮임. 뜨거운 침묵 |
| 잠식된 성채 | 차가운 회색, 어두운 남색 | 한때 영웅의 성채. 이제는 리치의 거점 |
| 암흑대지 | 순수한 흑, 희미한 보라 | 세계의 근원. 빛이 존재하지 않는 곳 |

## 9.3 허브 공간 — 멀린의 탑 잔해

- 런마다 돌아오는 공간. 멀린의 의지 상태에 따라 분위기 변화
- 초반: 탑 잔해, 희미한 마법 빛
- 중반: 빛이 줄어들고 어두워짐
- 후반: 탑 절반이 어둠에 잠식
- 최종 챕터 전: 한순간 밝아지며 멀린의 마지막 각성 연출

## 9.4 UI/UX 방향

| 요소 | 방향 |
|---|---|
| **HUD** | 최소화. HP 바, 메커닉 게이지, 스킬 쿨다운만 표시 |
| **메커닉 게이지** | 영웅별 고유 시각 표현 (신성 게이지=원형 빛, 콤보=선형 스택, 태양=시계 형태) |
| **아이템 그리드** | 퍼즐 보드 중심 UI. 배치 시 빛 연출 |
| **멀린의 서약** | 고딕 책 스타일 UI. 좌/우 선택이 책 페이지처럼 펼쳐짐 |
| **폰트** | NotoSansKR 기반, 제목은 세리프 계열 고딕 |
