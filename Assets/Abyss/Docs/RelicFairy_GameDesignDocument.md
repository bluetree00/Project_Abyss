# 2. 세계관 & 시나리오

## 2.1 배경 설정

아서왕 전설의 세계. 최고의 마법사 **멀린**이 의문의 외부 존재에 의해 살해된다.
그의 죽음과 동시에 세계는 부패하기 시작하고, 자연 · 고대 존재 · 인간 영웅들이 차례로 잠식된다.

멀린의 잔존 의지는 사후에도 흩어지지 않고 하나의 목적으로 수렴한다.
**"근원을 찾아라. 세상을 정상화하라."**

그는 세계 너머에서 **신성한 영혼**을 소환하고, 쓰러진 영웅들의 유물(육체)을 그 그릇으로 삼는다.
주인공은 영혼이다. 형체는 없다. 하지만 유물을 빌리면 싸울 수 있다.

> **모던 다크 동화 톤**
> 밝고 귀여운 동화가 아니다. 한때 빛났던 이야기가 부패하고 잠식된 세계.
> 잔해만 남은 동화책의 마지막 페이지 같은 분위기.

## 2.2 핵심 인물

### 멀린 (Merlin)
- 세계 최고의 마법사, 아서왕의 스승
- 게임 시작 시점에는 이미 사망
- **잔존 의지**로만 존재하며 주인공을 안내
- 런마다 돌아오는 허브 공간에서 목소리로 대화
- 진행하면서 점점 약해지다가 마지막에 진실을 고백

### 주인공 (신성한 영혼)
- 이름·형체 없음. 플레이어가 곧 영혼
- 멀린의 소환으로 세계에 존재
- 영웅의 유물(육체)을 빌려 전투
- 사망 시 멀린의 의지가 복구 → 재도전

### 모드레드 (Mordred) — 챕터 3 보스
- 원탁의 기사였으나 타락한 배신자
- 아서왕 전설에서도 아서를 배신한 인물
- 리치에게 잠식되기 전부터 어둠을 품었던 존재
- 영웅들 중 가장 먼저 리치의 도구가 된 자

### 리치 (The Lich) — 최종 보스
- 멀린의 육체를 탈취한 외부 존재
- 멀린의 전성기 마법 능력을 그대로 복사
- 세계 부패의 실질적 근원
- 쓰러지기 전 모르가나의 존재를 암시

### 모르가나 (Morgan le Fay) — 포스트 엔딩 암시
- 멀린의 제자이자 숙적
- 리치를 통해 멀린의 육체를 도구로 활용한 진짜 배후
- 리치 격파 후 목소리로만 등장 — 다음 챕터 암시

## 2.3 서사 아크 — 챕터별 빌드업

### 챕터 1 — 부패의 숲

**테마**: 혼돈, 원인 불명
**서사**: 세계가 이상하다는 것을 인지하는 단계. 멀린의 의지가 명확하게 주인공을 안내한다.

> *멀린의 의지: "영혼이여, 내가 힘을 불어넣어 주겠다. 근원을 찾아라."*

- 숲의 자연 수호자들이 부패
- 그린 나이트가 숲을 지배
- 영웅 유물 첫 발견 — "이 영웅은 왜 쓰러졌는가?"

**챕터 보스**: 그린 나이트 (The Green Knight)
- *가웨인과 녹색 기사* 전설의 인물
- 숲의 수호자가 부패로 거대화된 형태
- 가웨인 암시 유물을 사용하는 플레이어에게 특별 대사 출력

---

### 챕터 2 — 용암 대지

**테마**: 규모 확대, 부패의 깊이
**서사**: 고대 존재까지 잠식됐음을 확인. 멀린의 의지가 불안해지기 시작한다.

> *멀린의 의지: "이 부패는... 의지를 가지고 있어. 단순한 확산이 아니야."*

- 고대 용이 부패의 에너지에 잠식
- 영웅의 유물에서 기억 파편 발견 — "우리는 싸우다 쓰러진 게 아니라 — 당했다"

**챕터 보스**: 이 드레이그 고흐 (Y Ddraig Goch)
- 멀린이 직접 예언한 웨일스의 붉은 용
- 멀린이 예언했던 존재가 부패의 도구가 된 아이러니
- 격파 후 멀린: *"내가 예언한 존재가... 이렇게 쓰이다니."*

---

### 챕터 3 — 잠식된 성채

**테마**: 공포, 배후의 실체화
**서사**: 인간 영웅이 잠식됐음을 처음 목격. 리치의 직접 개입 흔적 발견.

> *멀린의 의지: "내 기억이 흐릿해지고 있어. 뭔가가 나를 갉아먹는 것 같아..."*

- 성채 전체가 리치의 부패 에너지로 점령
- 영웅들의 힘이 복사되고 있다는 단서 발견
- 리치가 의도적으로 영웅들을 분석·복사해왔음 확정

**챕터 보스**: 모드레드 (Mordred)
- 원탁의 기사, 리치에게 잠식된 배신자
- 격파 후 잠시 의식을 되찾으며 단서 제공
- *"그 자는... 모든 것을 복사했어. 너희까지도..."*

---

### 챕터 4 — 암흑대지 (최종)

**테마**: 근원, 비극적 클라이맥스
**서사**: 모든 진실이 드러나고 주인공이 최대 위기에 직면한다.

```
입장
  → 역대 영웅 복사체 연속전 (플레이어가 써온 유물의 복사체 포함)
  → 멀린의 마지막 메시지 재생
  → 리치 (멀린의 육체) 최종 보스전
  → 엔딩 + 모르가나 암시
```

**최종 챕터 직전 멀린의 대사**:
> *"알아냈어. 내 육체가... 잠식됐어."*
> *"부탁해. 막아줘."*

**리치 격파 후 엔딩**:
> 리치가 쓰러지며 마지막으로 웃음
> *"...멍청한 영혼. 이건 시작에 불과했는데."*
>
> 어딘가에서 모르가나의 목소리:
> *"잘했어. 실험은 끝났으니까."*
>
> 멀린의 의지 (희미하게):
> *"모르가나... 역시 그녀였군. 아직... 끝나지 않았어."*

## 2.4 멀린의 의지 — 내러티브 엔진

멀린의 의지 상태가 런 진행에 따라 변화하며 게임의 서사 온도를 조율한다.

| 런 구간 | 멀린 상태 | 허브 분위기 | 대사 톤 |
|---|---|---|---|
| 1~10런 | 강하고 명확 | 탑 잔해, 희미한 빛 | 단호하고 목적적 |
| 10~30런 | 불안, 단편적 | 빛이 줄어듦 | 걱정, 혼란 |
| 30~50런 | 희미해짐 | 탑이 더 어두워짐 | 쉰 목소리, 끊김 |
| 최종 챕터 | 마지막 각성 | 한순간 밝아짐 | 간절하고 절박함 |

# 3. 코어 게임 루프

## 3.1 거시적 루프

```
[허브: 멀린의 탑 잔해]
        ↓ 영웅 유물 + 장비 선택
[런 시작]
        ↓ 방 탐색 + 전투
[챕터 1~4 진행]
        ↓ 사망 또는 클리어
[허브 복귀]
        ↓ 재화 소비 (서약/해방/각성)
[강해진 영혼으로 재도전]
```

## 3.2 미시적 루프 (인게임)

```
[방 입장]
    → 방 버프 선택 (3~5개 중 1개)
    → 전투 수행
    → 아이템 획득 → 그리드 배치
    → 방 클리어 보상 (골드/아이템/봉인된 기억)
    → 다음 방 선택 (노드 맵)
[보스방]
    → 보스 처치 → 유물 코어 획득 (첫 격파 시)
    → 다음 챕터 또는 엔딩
```

## 3.3 씬 구성

| 씬 | 역할 |
|---|---|
| **로그인** | 계정 인증 |
| **로비** | 영웅 유물 선택, 장비 선택, 멀린의 서약 접근 |
| **스테이지맵** | 노드 기반 방 선택 |
| **게임씬** | 실제 전투 |
| **결과** | 런 결과, 재화 정산 |

# 4. 영웅 유물 시스템

## 4.1 시스템 개요

> "영웅의 이름은 잊혀졌다. 남은 건 유물뿐이다."

- 영웅 유물 = 쓰러진 영웅의 육체
- 정체는 **패시브 이름·스킬 이름·고유 대사**로만 암시
- 플레이어가 직접 유추하는 재미
- 모든 영웅이 모든 장비 사용 가능
- 영웅마다 **고유 패시브 + 고유 스킬 + 고유 메커닉** 보유

## 4.2 영웅별 상세 설계

---

### 유물 1 — [성배의 수호자] `기본 제공`

> 암시: 갈라하드 (Galahad) — 원탁에서 가장 성스러운 기사, 성배를 완성한 유일한 존재

**스타일**: 방어형 / 초보 친화 / 진입장벽 낮음

#### 기본 스탯
| 스탯 | 수치 |
|---|---|
| 기본 HP | 150 |
| 기본 공격력 | 80 |
| 기본 방어력 | 40 |
| 이동속도 | 표준 (1.0x) |

#### 고유 패시브
| 패시브명 | 효과 |
|---|---|
| **성스러운 방패** | 방어 입력 시 받은 피해의 30%를 전방 적에게 반사 |
| **아버지의 죄** | 피격 시 신성 게이지 +15 충전. 방어 성공 시 +25 충전 |

#### 고유 스킬: **성배의 빛**
- 쿨다운: 18초
- 효과: 전방 4m 범위 신성 폭발. 피해량 공격력 × 180%
- 신성 게이지 30 이상일 때 사용 시 범위 +50%, 피해량 +50%

#### 고유 메커닉: **신성 게이지**
```
최대 게이지: 100
충전:
  피격 시 +15
  방어 입력 성공 시 +25
  성배의 빛 사용 시 +20

만충(100) 달성 시:
  → 5초간 무적 + 공격력 150% + 신성 게이지 빛 연출
  → 이후 30초 쿨다운 (재충전 불가)
```

#### 메커닉 변형 아이템 예시
| 아이템명 | 효과 |
|---|---|
| *죄의 대가* | 공격 시에도 게이지 +8 충전 → 공격형 전환 |
| *성배의 축복* | 게이지 50마다 소폭 효과 발동 (무적 없이) → 지속형 |
| *순교의 서약* | 게이지 만충 효과 지속시간 5초 → 10초 |

---

### 유물 2 — [원탁의 균열] `봉인된 기억 3개`

> 암시: 랜슬롯 (Lancelot) — 원탁 최강의 기사, 금지된 사랑으로 원탁을 무너뜨린 비극의 존재

**스타일**: 고속 공격형 / 콤보 집중 / 중~고 난이도

#### 기본 스탯
| 스탯 | 수치 |
|---|---|
| 기본 HP | 120 |
| 기본 공격력 | 110 |
| 기본 방어력 | 20 |
| 이동속도 | 빠름 (1.2x) |

#### 고유 패시브
| 패시브명 | 효과 |
|---|---|
| **금지된 맹세** | 콤보 스택 1개당 공격력 +3% (최대 20스택 = +60%) |
| **원탁의 균열** | 처치 시 1.5초간 이동속도 +25% |

#### 고유 스킬: **최강의 일격**
- 쿨다운: 22초
- 효과: 0.3초 무적 후 단일 극딜 타격. 피해량 공격력 × 350%
- 현재 콤보 스택 수가 높을수록 피해량 증가 (스택당 +5%)

#### 고유 메커닉: **콤보 게이지**
```
최대 스택: 20
충전:
  공격 1회당 +1 스택
  스킬 사용 시 +3 스택

초기화 조건:
  1.5초 이상 공격 미실시
  피격 시 현재 스택 -5

효과:
  스택 1~9:  공격력 +3% × 스택수
```

# 5. 장비 & 빌드 시스템

## 5.1 장비 구조

모든 영웅이 모든 장비 사용 가능.
장비 = 액티브 스킬셋 + 기본 공격 방식 결정.

| 장비 유형 | 공격 스타일 | 특징 |
|---|---|---|
| **카타나** | 고속 연속기 | 짧은 사거리, 높은 공격 속도 |
| **대검** | 강타형 | 긴 사거리, 낮은 공격 속도, 높은 단타 피해 |
| **창** | 돌진/관통형 | 직선 관통, 중간 속도 |
| **활** | 원거리 | 긴 사거리, 투사체 |
| **검+방패** | 방어형 | 방어 기능 포함, 균형 스탯 |

## 5.2 아이템 이중 효과 구조

모든 아이템은 **범용 효과 + 영웅 친화 보너스** 두 줄 보유.

```
[분노의 맹세]
─────────────────────────
기본 효과:   공격력 +10%
─────────────────────────
원탁의 균열 친화:
  피격 시 콤보 게이지 +3 충전
─────────────────────────
```

- 범용 효과: 어떤 영웅이든 장착 가능
- 친화 보너스: 해당 영웅 장착 시만 발동
- 드롭 풀: 현재 영웅의 메커닉 기준 **가중치 조정** (친화 아이템 30% 상향)

## 5.3 영웅 × 장비 × 메커닉 조합표

| | 카타나 | 대검 | 창 | 활 | 검+방패 |
|---|---|---|---|---|---|
| **성배의 수호자** | 공격으로 게이지 충전 어려움 | 강타 후 피격 유도 → 탱딜 | 표준 | 원거리 게이지 지연 | 방어+게이지 최적 ★ |
| **원탁의 균열** | 콤보 빠른 충전 ★ | 리스크 고보상 | 돌진 콤보 | 안전 딜링 | 방어적 콤보 |
| **여정의 창** | 빠른 처치 → 스택 누적 | 보스킬러 빌드 ★ | 돌진+스택 시너지 ★ | 안전 누적 | 균형형 |
| **태양의 서약** | 강화 구간 연속딜 | 강화 구간 강타 ★ | 강화 구간 돌진 | 원거리 버스트 | 방어 유지 ★ |
| **비련의 화살** | 근접 → 거리 페널티 위험 | 근접 → 페널티 최고위험 | 히트앤런 | 거리 최적 ★ | 방어로 근접 방지 |

★ = 높은 시너지 조합

# 6. 런 내 성장 시스템

## 6.1 스탯 레이어 구조 (7단계 합산)

```
최종 스탯 =
  [1] 기본 (영웅 유물 기본 스탯)
+ [2] 서약 (멀린의 서약 영구 보너스)
+ [3] 유물 각성 (해금된 각성 효과)
+ [4] 장비 (선택한 장비 스탯)
+ [5] 아이템 (그리드 배치된 아이템 합산)
+ [6] 방버프 (현재 활성 방버프)
+ [7] 시너지 (그리드 시너지 Always/조건부)
```

## 6.2 아이템 시스템

### 아이템 획득 ~ 효과 적용 흐름
```
적 처치 또는 방 보상
  → 아이템 드롭 (등급별 확률)
  → Staging(임시 보관) — 효과 없음
  → 플레이어가 그리드에 배치
  → ItemEffectManager.Rebuild()
  → 효과 발동
```

### 아이템 등급 및 드롭 확률

| 등급 | 기본 확률 | 효과 특성 |
|---|---|---|
| Common | 55% | 범용 스탯 보정 |
| Rare | 30% | 조건부 효과 + 영웅 친화 보너스 |
| Epic | 12% | 메커닉 변형 |
| Legendary | 3% | 빌드 완전 전환 |

> 멀린의 서약 "아이템 등급 상승" 항목 보유 시 확률 조정
> 럭(Luck) 스탯이 높을수록 Rare 이상 확률 증가

### 아이템 효과 트리거 종류

| 트리거 | 발동 조건 |
|---|---|
| Always | 배치 즉시 영구 적용 |
| OnHit | 공격 적중 시 발동 |
| OnKill | 적 처치 시 발동 |
| OnRoomClear | 방 클리어 시 발동 |
| OnLowHp | HP 30% 이하 시 발동 |
| OnBossClear | 보스 처치 시 발동 |

## 6.3 그리드 시너지

아이템의 `shapeId`에 따라 퍼즐 보드에 블록 배치. 그리드 완성 시 시너지 발동.

### 시너지 트리거

| 트리거 | 조건 | 효과 방식 |
|---|---|---|
| **Always** | 그리드 완성 즉시 | 스탯 영구 반영 |
| **OnHit** | 공격 적중 시 스택 누적 | 최대 스택까지 누적, duration 초 유지 |
| **OnLowHp** | HP ≤ threshold | 조건 만족 시 활성화 |

### 그리드 완성 보상 예시

| 시너지명 | 트리거 | 효과 |
|---|---|---|
| *기사의 각오* | Always | 공격력 +15% |
| *원탁의 결속* | Always | MaxHP +50 |
| *심판의 일격* | OnHit | 스택당 공격력 +2% (최대 10스택) |
| *사지의 저항* | OnLowHp | 방어력 +40%, 이동속도 +15% |

## 7.3 유물 해방 (봉인된 기억 소비)

> "기억이 쌓이면 잠들어 있던 영웅의 유물이 깨어난다."

| 유물 | 비용 | 누적 필요량 |
|---|---|---|
| 원탁의 균열 | 봉인된 기억 ×3 | ×3 |
| 여정의 창 | 봉인된 기억 ×5 | ×8 |
| 태양의 서약 | 봉인된 기억 ×8 | ×16 |
| 비련의 화살 | 봉인된 기억 ×12 | ×28 |

### 봉인된 기억 획득 방식

확률 드롭에 의존하지 않는다. 챕터 보스 처치에 보장 수량이 연결된다.

| 획득처 | 수량 | 조건 |
|---|---|---|
| 챕터1 보스 처치 | ×1 보장 | 봉인 상태 격파 포함 |
| 챕터2 보스 처치 | ×1 보장 | 봉인 상태 격파 포함 |
| 챕터3 보스 처치 | ×2 보장 | 봉인 상태 격파 포함 |
| 챕터4 보스 처치 | ×2 보장 | 봉인 상태 격파 포함 |
| 이벤트방 / 엘리트방 확률 드롭 | ×0~1 | 보너스 성격 |

> 풀클리어 1런 = 보장 6개 + 기대 드롭 1~2개 ≈ 7~8개/런
> 전체 해방(×28) 기준 약 4~5런의 풀클리어 또는 챕터별 부분 클리어 조합

### 사망 카운터 시스템

> "고통도 기억이다."

5회 사망 누적 시 봉인된 기억 ×1 보장 지급. 카운터 초기화.

```
사망 카운터: 0 ─ 1 ─ 2 ─ 3 ─ 4 ─ [5] → 봉인된 기억 +1
```

- 리치를 못 잡더라도 반복 시도 자체가 영웅 해방에 기여
- 멀린 대사: *"고통도 기억이다. 받아라."*

## 7.4 유물 각성 (유물 코어 소비)

> "유물이 진짜 이름과 힘을 되찾는다. 영웅의 진정한 각성."

각 영웅 유물마다 Tier 1~3 각성 존재. 각성할수록 고유 메커닉이 심화된다.

### 각성 비용

| 각성 Tier | 필요 유물 코어 | 영웅 1개 누적 | 효과 방향 |
|---|---|---|---|
| Tier 1 | ×1 | ×1 | 메커닉 수치 강화 |
| Tier 2 | ×3 | ×4 | 메커닉에 새로운 조건 추가 |
| Tier 3 | ×6 | ×10 | 메커닉 근본 확장 |

> 영웅 5개 전체 완전 각성 기준 총 코어 ×50 필요.

### 코어 획득 경로

| 경로 | 수량 | 조건 |
|---|---|---|
| 리치 첫 격파 | ×4 일괄 지급 | 전체 보스 봉인 파열 연출과 함께 |
| 완전 해방 보스 첫 격파 | ×1 | 리치 격파 이후 각 보스 첫 완전 격파 |
| 잔류 각인 교환 | ×1 / 각인 ×5 | 반복 획득 경로 (허브에서 교환) |

> 리치 첫 격파로 받은 코어 4개로 원하는 영웅 Tier 1 각성 즉시 가능.
> 장기 목표: 잔류 각인을 통해 나머지 코어 수집 (보스 재격파 누적).

### 성배의 수호자 각성 예시

| 각성 | 효과 |
|---|---|
| Tier 1 | 신성 게이지 만충 효과 지속 5초 → 8초 |
| Tier 2 | 신성 게이지 50% 이상 시에도 소폭 효과 발동 (무적 없이, 공격력 +30%) |
| Tier 3 | 신성 게이지 만충 후 쿨다운 중에도 피격 시 게이지 소량 재충전 가능 |

## 7.5 보스 봉인 시스템

> "리치가 씌운 봉인. 영혼이 닿을 때마다 균열이 생긴다. 리치가 쓰러져야 완전히 끊어진다."

### 구조 개요

보스는 리치의 봉인에 억압된 채 전투에 임한다. 플레이어의 영혼이 접촉할 때마다 봉인에 균열이 누적되며, 리치 격파 시 모든 봉인이 완전 파열된다.

| 단계 | 조건 | 보스 상태 | Phase | 보상 |
|---|---|---|---|---|
| **봉인 상태** | 리치 미격파, 1차 조우 | HP 0 → 균열 연출 후 퇴각 | Phase 1만 | 봉인된 기억 보장 + 잔재 |
| **봉인 균열 예고** | 리치 미격파, 2차+ 조우 | Phase 2 형태를 짧게 노출 후 다시 봉인 | Phase 1 + Phase 2 예고 | 봉인된 기억 보장 + 잔재 |
| **완전 해방** | 리치 격파 이후 | 봉인 없음. 진짜 격파 가능 | Phase 1 + Phase 2 완전 해금 | **유물 코어 ×1** |
| **부패 변이** | 완전 해방 후 재도전 | 랜덤 변이 수식어 1개 추가 | Phase 1 + 2 + 변이 | 잔류 각인 ×3~5 |

### 봉인 균열 예고 — 조우 횟수별 Phase 2 노출 시간

| 조우 횟수 | Phase 2 노출 시간 | 연출 |
|---|---|---|
| 1차 | 없음 | HP 0 → 봉인 파열 → 퇴각 |
| 2차 | 1~2초 | Phase 2 형태 순간 출현 후 다시 봉인 |
| 3차 | 3~4초 | 더 긴 노출, 공격 1회 |
| 4차+ | 5초+ | 확연한 Phase 2 예고 |

멀린 대사 (균열 심화):
- 2차: *"봉인에 균열이 생겼어. 네 영혼이 닿았다."*
- 3차: *"균열이 깊어지고 있어. 리치의 힘이 흔들린다."*
- 4차+: *"이제 조금만 더다..."*

### 리치 격파 — 봉인 완전 파열

```
리치 사망
  ↓
전체 챕터 보스 봉인 파열 연출 (허브에서 동시 재생)
  ↓
유물 코어 ×4 일괄 지급 (챕터당 1개)
  ↓
멀린: "리치가 쓰러졌다. 모든 봉인이... 끊어졌어."
      "이제 그들의 진짜 모습과 싸울 수 있다."
  ↓
이후 런부터 모든 보스 완전 해방 상태로 조우
```

### 부패 변이 수식어 풀

완전 해방 이후 재도전 시 랜덤 수식어 1개 부여:

| 분류 | 수식어명 | 효과 |
|---|---|---|
| 공격 | 분노의 부패 | 공격력 +40%, 공격 속도 +20% |
| 공격 | 관통의 저주 | 모든 공격 방어 무시 |
| 공격 | 연쇄의 광기 | 피격 시 주변에 연쇄 피해 |
| 방어 | 철갑의 잠식 | 받는 피해 -40%, HP 회복 불가 |
| 방어 | 재생의 부패 | 초당 최대HP 0.3% 회복 |
| 환경 | 독안개 확산 | 전장 외곽에서 독 안개 서서히 수축 |
| 환경 | 중력 왜곡 | 플레이어 대시/점프 거리 -30% |
| 특수 | 기억 역류 | 이번 런 첫 획득 아이템 효과를 보스가 사용 |

## 7.6 성장 시간대 설계

| 구간 | 주요 목표 | 재화 소비처 | 멀린 상태 |

## 8.2 단일 세계 맵 시스템

### 핵심 컨셉

> **"맵 전체가 처음부터 존재한다. 다만, 길이 막혀 있을 뿐이다."**
>
> 챕터 = 하나의 거대한 물리 세계.
> 부패의 물질(흑수·용암·안개·공허)이 세계를 뒤덮고 있으며,
> 존을 클리어·선택하면 그 구역의 장벽이 물러난다.
> 플레이어는 드러나는 경로를 따라 보스 구역을 향해 직접 걸어 나아간다.

**기존 타일 맵 방식과의 차이**

| 항목 | 구 방식 (타일 맵) | 신 방식 (단일 세계) |
|---|---|---|
| 세계 존재 방식 | 방 선택 시 맵 인스턴스 생성 | 전체 맵이 처음부터 물리적으로 존재 |
| 이동 방식 | 타일 클릭 → 씬 로드 | 플레이어가 직접 지형을 걸어서 이동 |
| 장벽 처리 | UI 상 봉인 표시 | 장벽 물질이 실제 지형을 덮고 있음 |
| 탐험감 | 없음 (추상적 노드) | 있음 (발견·탐험 감각) |

```
 L9:         [Z21]    [Z22]
 L8:    [Z18]    [Z19]    [Z20]
 L7:    [Z15]    [Z16]    [Z17]
 L6:    [Z12]    [Z13]    [Z14]
 L5:    [ Z9]    [Z10]    [Z11]
 L4:    [ Z6]    [ Z7]    [ Z8]
 L3:         [ Z4]    [ Z5]
 L2:         [ Z2]    [ Z3]
```

### 존 연결 구조 (슬라이딩 윈도우)

각 존은 다음 레이어의 인접 2~3개 존과 연결된다.
가장자리 존: 2개 연결 / 중앙 존: 3개 연결.

```
Z1  → Z2, Z3
Z2  → Z4, Z5        Z3  → Z4, Z5
Z4  → Z6, Z7        Z5  → Z7, Z8
Z6  → Z9, Z10       Z7  → Z9, Z10, Z11   Z8  → Z10, Z11
Z9  → Z12, Z13      Z10 → Z12, Z13, Z14  Z11 → Z13, Z14
Z12 → Z15, Z16      Z13 → Z15, Z16, Z17  Z14 → Z16, Z17
Z15 → Z18, Z19      Z16 → Z18, Z19, Z20  Z17 → Z19, Z20
Z18 → Z21, Z22      Z19 → Z21, Z22       Z20 → Z21, Z22
Z21 → Z23, Z24      Z22 → Z23, Z24
Z23 → Z25           Z24 → Z25
Z25 → Z26
```

존을 클리어하면 연결된 다음 레이어 존들이 공개되고, 플레이어는 그중 하나를 선택한다.

---

### 존 상태 정의

| 상태 | 설명 | 시각적 표현 |
|---|---|---|
| **Sealed** | 장벽 물질로 봉인됨 | 장벽이 지형을 덮음, 지형 실루엣만 보임 |
| **Available** | 인접 존 클리어로 선택 가능 | 장벽 일부 후퇴, 존 컨셉 아이콘 표시 |
| **Selected** | 플레이어 선택, 개방 연출 중 | 장벽 완전 후퇴 애니메이션 재생 |
| **Active** | 현재 플레이 중 | 존 구역 하이라이트 |
| **Cleared** | 클리어 완료 | 체크포인트 활성화, 이동 가능 |

### 부패 압박 시스템 (Corruption Pressure)

클리어하지 않고 지나친 존은 챕터 보스를 강화한다.

| 미클리어 존 수 | 보스 강화 |
|---|---|
| 0 | 기본 상태 |
| 1~3 | 보스 HP +5% / 존 |
| 4~7 | HP +5% / 존 + 패턴 1개 추가 |
| 8+ | HP +5% / 존 + 패턴 2개 추가 + 필드 부패 이펙트 |

> 최단 경로만 달리면 보스가 강해지는 구조. 탐험 FOMO를 자연스럽게 유도한다.

---

### 히든 보상 시스템

일부 존에는 지형 내 **히든 보상**이 숨겨져 있다.
전투 중 발견 가능한 숨겨진 장소(잔해 뒤, 고목 위, 절벽 아래 등).

| 항목 | 내용 |
|---|---|
| 히든 보상 존 비율 | 26존 중 약 8존 |
| 보상 타입 | 재화 캐시 / 소형 아이템 / 서사 단편 |
| 발견 조건 | 전투 중 지형 탐색 (별도 상호작용 불필요) |

---

### 단축로 시스템 (Shortcut)

특정 조건의 인접 존 두 곳이 모두 클리어될 때 **단축 경로**가 개방된다.

- 단축로: 이미 클리어한 존 사이를 직접 연결하는 지형 통로
- 용도: 상점 재방문, 탐색, 체크포인트 복귀
- 조건: 단축로 양 끝 존이 모두 Cleared 상태

|---|---|---|
| 1 | 명확하고 단호 | 힘찬 음성, 장벽 빠르게 후퇴 |

| 3 | 단편적, 끊김 | 음성 잡음 섞임, 장벽 후퇴 멈칫거림 |

## 8.3 보스 상세 설계

### 그린 나이트 (챕터 1)

**설정**: 숲의 수호자가 부패로 거대화된 형태. 원래는 기사들을 시험하는 존재였으나 부패에 잠식됨.

| 항목 | 내용 |
|---|---|
| 발동 조건 | HP 50% 이하 진입 시 |
| 전환 연출 | 숲 전체 부패 에너지로 물들며 새벽 소멸 |

## 8.6 레벨 디자인 원칙 (Hades / Dead Cells 적용)

### 6대 아레나 패턴

각 전투 존은 다음 6가지 패턴 중 하나를 기반으로 설계된다.
복합 패턴(두 가지 혼용)은 레이어 후반부(L6+)부터 적용한다.

| 패턴 코드 | 이름 | 핵심 구조 | 주요 위협 |
|---|---|---|---|
| **PINCER** | 협공형 | 플레이어 측면 양방에서 몬스터 진입 | 회피 루트 양측 압박 |
| **RING** | 포위형 | 중앙 진입 후 사방에서 몬스터 등장 | 360도 방어 부담 |
| **CORRIDOR** | 선형형 | 좁은 통로에서 정면 압박 | 이동 경로 제한 |
| **ISLAND** | 도서형 | 발판 위 전투, 추락 시 피해·사망 | 낙사 위협 |
| **TIERED** | 고저형 | 고·저지대 혼재, 원거리·근거리 혼용 | 고저 차이 활용 적 |
| **LABYRINTH** | 미로형 | 엄폐물·기둥으로 시야 분산 | 기습, 시야 제한 |

---

### Hades 3대 레벨 디자인 규칙

1. **입장 안전 1초**: 플레이어 진입 지점 반경 5m는 항상 비워둔다. 입장과 동시에 피격되는 상황 절대 금지.
2. **탈출로 2개 이상**: 어떤 상황에서도 플레이어가 전진·후퇴할 수 있는 경로가 2개 이상 존재해야 한다.
3. **엄폐물 4~6개**: 방당 엄폐물(바위, 나무, 잔해)은 최소 4개, 최대 6개. 과밀 시 몬스터 경로가 막힘.

### Dead Cells 수직성 원칙 적용

- 탐험 보상(히든 보상)은 수직 이동(등반, 낙하)으로 발견 가능한 위치에 배치한다.
- 단축로는 수직 낙하 통로로 구현하여 탐험 감각을 강화한다.
- 각 존의 히든 보상은 높이 차이가 있는 지점(고목 위, 절벽 아래)에 배치한다.

# 9. 비주얼 & 톤 방향

## 9.1 아트 방향성

**모던 다크 동화 (Modern Dark Fairy Tale)**

> 한때 빛났던 동화의 페이지가 잠식되고 부패한 세계.
> 귀엽거나 밝지 않다. 어둡고 잔인하지만 아름다운 잔재가 남아있다.

| 요소 | 방향 |
|---|---|
| **색감** | 채도 낮은 어두운 팔레트. 포인트 컬러로 신성한 금빛·청백 사용 |
| **배경** | 부패한 자연 + 중세 건축 잔해. 완전히 파괴되지 않은 "한때 아름다웠던" 느낌 |
| **캐릭터** | 실루엣 중심. 영웅 유물은 갑옷·외형에서 원작 힌트만 남김 |
| **UI** | 고딕 라인 기반 모던 미니멀. 과도한 장식 없이 정보 중심 |
| **이펙트** | 신성 게이지는 금빛, 부패 에너지는 보라·흑색, 불꽃은 붉은 주황 |

## 9.2 챕터별 비주얼 톤

| 챕터 | 메인 컬러 | 분위기 |
|---|---|---|
| 부패의 숲 | 탁한 초록, 검은 보라 | 생명이 부패한 숲. 덩굴이 건물을 삼킴 |
| 용암 대지 | 붉은 주황, 검정 | 고대 지형이 용암으로 뒤덮임. 뜨거운 침묵 |
| 잠식된 성채 | 차가운 회색, 어두운 남색 | 한때 영웅의 성채. 이제는 리치의 거점 |
| 암흑대지 | 순수한 흑, 희미한 보라 | 세계의 근원. 빛이 존재하지 않는 곳 |

## 9.3 허브 공간 — 멀린의 탑 잔해

- 런마다 돌아오는 공간. 멀린의 의지 상태에 따라 분위기 변화
- 초반: 탑 잔해, 희미한 마법 빛
- 중반: 빛이 줄어들고 어두워짐
- 후반: 탑 절반이 어둠에 잠식
- 최종 챕터 전: 한순간 밝아지며 멀린의 마지막 각성 연출

## 9.4 UI/UX 방향

| 요소 | 방향 |
|---|---|
| **HUD** | 최소화. HP 바, 메커닉 게이지, 스킬 쿨다운만 표시 |
| **메커닉 게이지** | 영웅별 고유 시각 표현 (신성 게이지=원형 빛, 콤보=선형 스택, 태양=시계 형태) |
| **아이템 그리드** | 퍼즐 보드 중심 UI. 배치 시 빛 연출 |
| **멀린의 서약** | 고딕 책 스타일 UI. 좌/우 선택이 책 페이지처럼 펼쳐짐 |
| **폰트** | NotoSansKR 기반, 제목은 세리프 계열 고딕 |
