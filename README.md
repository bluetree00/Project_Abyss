프로젝트 A (로그라이크 액션 게임)

프로젝트 개요

로그라이크 액션 장르의 PC 플랫폼 게임으로, 스테이지 클리어를 통해 장비 아이템과 퍼즐 시스템으로 캐릭터를 강화해 최종 챕터를 목표로 진행하는 게임입니다.

개발 기간

2024.12 ~ 진행 중

사용 기술 및 엔진

Unity 3D

ScriptableObject, Addressables, State Machine 패턴

주요 개발 사항

플레이어 및 몬스터 상태 머신(State Machine) 구조 설계

Managers 패턴 기반 시스템 관리

최소 스패닝 트리(MST)를 활용한 랜덤 스테이지 구성

자동화된 캐릭터 스텟 관리 시스템 구축

오브젝트 풀링을 통한 리소스 최적화

아이템과 퍼즐 시스템 구현 및 UI 연동
