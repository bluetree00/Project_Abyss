프로젝트 Abyss (로그라이크 액션 게임)

프로젝트 개요

로그라이크 액션 장르의 PC 플랫폼 게임으로, 스테이지 클리어를 통해 장비 아이템과 퍼즐 시스템으로 캐릭터를 강화해 최종 챕터 클리어를 목표로 진행하는 게임.

사용 기술 및 엔진

Unity 3D

대표 기술 

ScriptableObject, Addressables 통한 데이터 자동 직렬화  

Layer State Machine 패턴 

Managers 디자인 패턴을 통한 매니저 모듈화.

진행된 개발 내용

-플레이어, 몬스터의 LayerFSM구조 개발

-매니저를 관리하는 Managers 디자인 패턴 구조 설계.

-New Input System 바인딩을 통한 입력 인풋 버퍼 구조 설계

-인터페이스, Unity ScriptableObject 사용한 자체 장비 시스템 제작.

-뒤끝 서버를 연동하여 게임 로그인 구현 플레이어 데이터 DB 보관 관리 기능

-서버 테이블 인게임 구조 설계 및 게임 데이터 반영.

-Unity Addressable을 사용한 오브젝트 풀러 설계로 리소스 최적화.

-유저의 스텟 증가를 반영한 아이템 퍼즐 시스템 설계

-게임의 기본 랜더링 방식과 라이팅 환경 세팅.

-플레이어 장비 어빌리티 시스템 개발을 통한 플레이어 캐릭터 모듈화.

-몬스터의 기본 행동 구조 및 공격, 회피 패턴 개발.

-UI 바인딩 구조를 사용한 필요 UI 자동 생성 구조 개발.

-플레이어 인벤토리, 인벤토리 데이터 정보 확인 UI 개발.
